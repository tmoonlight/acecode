# 像素办公室界面约束

模式：Operate。用途是在桌面像素场景中查看真实 agent 状态，并切换所观察的主会话。视觉规则见 [DESIGN.md](DESIGN.md)，场景实现见 [agent_office_pet.html](agent_office_pet.html)。

## 视觉与首屏

透明等距房间占据主体，顶部仅保留最近会话和跟随开关。原作家具、五套布局模板及像素角色保持；场景不扩展为管理页面。首次连接前显示空房间，连接或读取提示位于控制条下方。

## 会话与成员

- 最近列表跨工作区汇总，按用户最后发送消息的时间降序取五个主会话，排除已归档会话和子会话。
- 跟随默认开启，观察主窗口当前会话；手动选择会话后关闭跟随。重新开启后回到主窗口当前会话。
- 房间种子来自会话 ID；会话切换清理旧角色与瞬态效果，同一会话刷新保持布局和角色外观。
- 房间显示一个主 agent 与最多七个子 agent；更多成员通过 `+N` 列表查看。列表展示完整当前成员集合及状态，展开期间持续更新。

## 状态表达

| 真实状态 | 场景表达 |
| --- | --- |
| 尚未开始执行 | 待命；没有演示角色补位 |
| 推理、调用工具 | 思考或工作；工具执行时显示与聊天共源的图标 |
| 等待授权、等待回答、重试 | 保留各自的明确状态文案 |
| 主 agent 成功完成 | 留在主工位，显示 `zzz`；下一轮开始后恢复执行状态 |
| 子 agent 成功完成 | 离开工位；后续任务出现时再按真实成员恢复 |
| 执行失败或停止 | 本轮保留失败或停止状态，不能表现为成功休息 |
| 整理上下文 | 显示整理状态及机器人提示；文件堆随后跟随新上下文比例 |

文件堆反映当前上下文使用量相对窗口容量的比例，不使用会话累计消耗量。容量未知时不绘制文件堆，不能把未知当作零用量。消息信封由真实成员变化或消息记录触发；减少动态效果偏好下抑制该动效。

## 桌面交互

- 拖动场景移动窗口；单击角色查看名称和状态，双击打开对应会话。
- 滚轮或把手调整窗口大小，把手双击恢复默认大小；控件和成员列表中的滚动不触发场景缩放。
- 右键交给原生菜单。桌面窗口保持透明、置顶及不抢焦点约束；主动打开会话属于独立操作。
- 成员列表独立滚动，点击成员打开会话并关闭列表，Escape 关闭列表；列表区域与原生命中区域保持同步。
- 连接中断时保留最后快照并显示重连提示，不能继续伪造实时进展。

## 依据与验证边界

规则来自当前 HTML、`desktopOfficeState.js`、`desktopOfficeController.js` 与原生宠物窗口实现。本文只记录已实现行为与视觉约束，不作为原生窗口实测通过的证明；验收状态以该变更的任务和验证记录为准。
