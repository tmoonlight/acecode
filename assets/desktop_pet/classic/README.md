# 经典桌面宠物素材

Clippy（43 个动作）与 Rover（29 个动作）原始 PNG 精灵图和动作数据来自 [clippyjs/clippy.js](https://github.com/clippyjs/clippy.js)，固定提交和 SHA-256 见 `sources.json`。`preview.png` 直接裁取原图的 RestPose 首帧，仅用于设置中的预览。

## 趴边偷看（clippy/peek.png、rover/peek.png）

宠物拖到屏幕左/右边缘吸附后改用各自目录下的 `peek.png`：两帧并排（左睁眼、右闭眼），透明背景，画面右缘就是它躲着的那条屏幕边（贴左边时页面水平镜像）。不来自上游项目，2026-10-16 用 Codex 的内置图像生成（codex-cli 0.162）绘制，以本目录精灵图的整张图与 RestPose / Idle 首帧作为风格参考，要求同一角色设计与画风：回形针把上半截钢丝和两只大眼睛从画面右缘探进来，rover 探出脑袋、两只前爪扒着右缘。闭眼帧由同一张图做「只闭眼、其余不变」的编辑，再只把眼睛区域贴回睁眼图，眨眼时其余像素不动。处理：纯绿背景抠成透明并去绿边，两帧同裁，按眼睛大小与原帧一致缩到精灵分辨率（回形针 29×75、rover 41×56 每帧），alpha 只留全透明 / 不透明，颜色映射到对应 `map.png` 实际用到、且不偏绿的调色板颜色，所以和原帧一样是不平滑放大的像素画。换图时要按眼睛重新量缩放，页面里的倍数见 `classic_pet.js` 的 `PEEK` 表。
