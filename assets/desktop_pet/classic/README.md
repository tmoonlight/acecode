# 经典桌面宠物素材

Clippy（43 个动作）与 Rover（29 个动作）原始 PNG 精灵图和动作数据来自 [clippyjs/clippy.js](https://github.com/clippyjs/clippy.js)，固定提交和 SHA-256 见 `sources.json`。`preview.png` 直接裁取原图的 RestPose 首帧，仅用于设置中的预览。

## 高清帧（hd/）

原精灵图只有 124×93（Clippy）/ 80×80（Rover）、256 色抖动，放大到 350 像素以上满是锯齿。2026-10-31 起页面不再使用 `map.png`，改用 `hd/` 里逐帧重画的高清版：Clippy 496×372、Rover 360×360（鲸鱼娘 512×512，见 `../whale/README.md`）。`map.png` 与 `agent.js` 保持上游原样：前者是重画的参考和对齐基准，后者仍提供每个动作的帧序、时长和分支。

重画用 Codex 的内置图像生成（codex-cli 0.166，`image_generation`），脚本在 `scripts/desktop_pet/`，按顺序运行：

1. `hd_make_grids.py`：收集页面会播放的动作（`classic_pet.js` 的 `PROFILES` 加 RestPose；鲸鱼娘全部动作）用到的帧，合并只差抖动噪点的近似重复帧，按播放顺序每 9 帧（鲸鱼娘 4 帧）排成一张参考网格，原帧最近邻放大到 4 / 5 倍、纯绿背景。重跑时保留已有网格，只为新增的帧排新网格。
2. `hd_codex_redraw.py`：8 路并行调用 `codex exec`，每次附两张图：参考网格，以及同一角色的高清定稿图（先单独重画的一张 RestPose，用作风格锚点，保证各次重画的材质、线条一致）。提示要求网格、每格的姿势位置大小颜色都不变。输出纯绿背景抠成透明（按绿色溢出量做软边、去绿边），切格后按原帧轮廓对齐：同一张图共用一个缩放（Codex 在一张图内比例稳定），大格各自微调位置，小目标（只露出眼睛、刚从纸里钻出来等）沿用大格的位置只做小范围微调。大格轮廓重合度低于 0.85 或小格低于 0.45 时重画，最多 3 次；`--reselect` 从已有的各次尝试里重新挑对得最好的一张。
3. `hd_assemble.py`：对齐后的帧缩到发布尺寸（Rover 由 5 倍缩到 4.5 倍），裁掉透明边，按动作的播放顺序打包成每张不超过 2048×2048 的 WebP（质量 75，透明通道无损），写出 `hd/frames.js`：`frames` 以原精灵偏移 `"x,y"` 为键，值为 `[图序号, x, y, 宽, 高, 帧内偏移 x, 帧内偏移 y]`；`animations` 列出每个动作用到的图，也决定哪些动作可播放。页面只解码播放位置往后 16 帧所在的图，超过约 1600 万像素时丢掉最久没用的。`scripts/embed_desktop_pet.py` 按序号嵌入全部图（三只合计约 17.7MB）。

## 趴边偷看（clippy/peek.png、rover/peek.png）

宠物拖到屏幕左/右边缘吸附后改用各自目录下的 `peek.png`：两帧并排（左睁眼、右闭眼），透明背景，画面右缘就是它躲着的那条屏幕边（贴左边时页面水平镜像）。不来自上游项目：2026-10-16 先用 Codex 画出精灵分辨率的版本（回形针把上半截钢丝和两只大眼睛从画面右缘探进来，rover 探出脑袋、两只前爪扒着右缘），2026-10-31 由 `scripts/desktop_pet/hd_peek.py` 以那一版为参考、以高清定稿图为风格锚点，用 Codex 重画到与高清帧相同的倍数（回形针 4 倍、rover 4.5 倍），按原偷看图的轮廓对齐。闭眼帧只取两帧原图有差别的眼睛区域（外扩、羽化）贴到睁眼帧上，眨眼时其余像素不动。偷看图与高清帧同倍数，所以 `classic_pet.js` 的 `PEEK` 表里两者的 `ratio` 都是 1。
