# 功能操作说明

按用户问题阅读对应章节。核对范围为 2026-10-01 至 2026-10-09 的 OpenSpec 与当前源码。
安装版本较旧时，以该版本可见入口为准。

## 记忆与个性化

- **设置 > 个性化 > 记忆**：开关使用记忆，查看全局和当前工作区条目，点击条目查看、编辑或删除。
  作用域重置会清空该范围的条目、索引和观察，需在界面确认，不影响另一个范围。
- 全局目录为 `~/.acecode/memory/`；工作区目录为 `~/.acecode/projects/<工作区标识>/memory/`。
  同一工作区的 ACECode worktree 共用工作区记忆，无工作区任务只用全局记忆。
- `/memory list`、`view 名称`、`forget 名称`、`reload` 在 TUI 和 Web/Desktop 可用。
  `/memory edit 名称` 在 Desktop 提示前往个性化设置，在 TUI 调用编辑器。
- `/memory off` 和 `/memory on` 控制当前会话，恢复会话后仍保留该选择。
- 记忆上下文在会话首次请求时形成快照，中途写入不会立刻改写已有快照；新会话或压缩后重建。
  `memory_read` 可直接读取最新磁盘条目。
- **记忆摘要**默认关闭，开启后会额外调用模型；空闲约 30 分钟后提炼观察，再批量整合。
  可选摘要模型，查看待整合数量、最近时间和错误。`/memory flush` 立即整理，未开启摘要时只给说明。
- 记忆属于历史信息，依赖其中路径、命令或项目状态前先核实，以用户当前指令为准。

## 侧边聊天与主任务控制

- 从会话右上角气泡按钮、打开工具菜单或 `/side`、`/btw` 打开浮窗，可拖动、调整大小、继续追问。
- 每次提问结合主任务当前安全上下文快照与先前有效旁问记录，不写入主任务历史，也不改变主任务目标。
- 支持的只读工具为 `file_read`、`grep`、`glob`、`lsp`，还受当前能力和路径规则限制。
  需要确认的读取会被拒绝；写入、Shell、MCP、子代理操作应回到主对话。
- 生成时可停止；最小化停止生成并保留临时记录；清空会停止并移除记录；切换主会话会清空。
  不将浮窗记录承诺为持久化会话。TUI 的 `/side`、`/btw` 仍为单次旁问。
- 普通消息在忙碌时排队；卡片的插话在下一模型边界补充当前回合，`/turn` 则中断当前回合
  并立即提交指导。停止和中断都不会撤销已发生的文件写入。

## 蜂群模式

输入框加号菜单提供互斥的 **蜂群模式（星型）**、**蜂群模式（网状）**，也可关闭。

- 星型：主代理拆分并汇总，一层子任务，适合独立分工。
- 网状：子代理可继续派生下级、互相通信和接受后续任务，适合分层协作。
- 选择随会话保存；开启模式本身不立即派生任务。仍有活动子代理时不能关闭网状模式。
- 默认同时驻留 4 个代理，包含主代理；这是同时加载数量，不是整棵树只能有 4 个历史任务。
  空闲代理可暂时卸载，需要时恢复。
- 在 **后台任务**查看子任务、打开会话、停止任务并处理带来源的权限请求和提问。
  子会话长期保留，跟随主会话归档/删除，不能单独归档或删除。
- 子代理共享工作目录，独立上下文不代表独立 worktree。需要并行写入时明确文件责任范围。
- TUI 使用 `/swarm star|mesh|off`；headless 使用 `--swarm star|mesh|off`。
  Desktop 优先使用加号菜单，不假设存在 TUI 的全部斜杠入口。

## 智能定时任务

**定时任务 > 智能添加定时任务**只预填草稿，用户补全时间与任务内容并发送后才开始创建。
也可直接要求“每天上午 9 点检查此项目”，由 `scheduled-task` 技能调用内置工具。

- 具体时间、天数不能保留为 `X点`、`X天`。核对时区、有效期和下一次执行时间。
- 创建工具会询问执行权限，可选默认权限或完全访问；只有成功结果才表示任务已保存。
- 手动表单的新任务默认完全访问，保存前主动检查。worktree 默认关闭。
- 保存后在定时任务页查看、修改、停用、删除和查看运行记录，不需要让创建聊天一直等待。
- daemon 必须运行；离线错过不补跑，同工作区已被定时任务占用时可能跳过。
  不承诺每轮必定新建或复用某个会话。监控任务沿用用户的通知要求。

## 消息通道

打开 **设置 > 集成 > 消息通道**，支持 QQ、微信、飞书、钉钉、Telegram、Discord、LINE。
卡片提供连接和管理；连接后的取消连接、更换凭据、机主/访问管理、计数与错误详情集中在管理弹框。
连接向导和管理弹框通过关闭按钮关闭，点击外部不会关闭。

| 平台 | 开始方式与必要条件 |
| --- | --- |
| QQ | 手机 QQ 扫码；也可手填 AppID/AppSecret。平台认证状态影响可用用户与群范围。 |
| 微信 | 微信扫码确认，扫码账号成为唯一机主；仅私聊。 |
| Telegram | 填 BotFather Token，使用绑定链接或手机相机扫码后点开始。 |
| 飞书/Lark | 填 App ID/App Secret；连接在线时配置长连接事件、权限并发布应用。 |
| 钉钉 | 填 Client ID/Client Secret，配置 Stream 模式和机器人权限。 |
| Discord | 填 Bot Token，启用 Message Content Intent，再邀请机器人进入服务器。 |
| LINE | 填 Channel ID/secret，启用 Webhook；需要公网 HTTPS 地址或已安装 cloudflared 的临时隧道。 |

除 LINE 的回调需求外，由本机主动连接；各平台使用 ACECode 的代理设置。飞书、钉钉、Discord、
LINE 通过向导的一次性六位绑定码绑定机主。陌生人和群需批准；群内通常还需 @机器人及成员授权。
同一飞书/钉钉应用不要同时连到多个机器人客户端，以免消息被分流。

聊天内常用 `/help`、`/status`、`/stop`、`/new`、`/sessions`、`/resume 编号`、`/model 名称`；
`/approve`、`/deny`、`/aq` 处理确认或提问，具体参数以 `/help` 为准。
机主可切换任意会话，其他人只可切换自己的会话；同一会话不能同时绑定多个 IM 会话。
侧边栏使用平台图标标识绑定；Desktop 中产生的回复也可能发回已绑定聊天。

原有渠道插件的 `/rc` 及 Webhook 配置是另一路接入；不要拿插件命令表替代内置 IM 命令表。
真实账号可用性还依赖平台配置和网络，不能将本地模拟测试描述为所有平台都完成实测。

## 虚拟办公室

Windows/macOS 原生 Desktop 支持，默认关闭。首次邀请可以拒绝，之后仍可从左下角齿轮菜单的
**显示虚拟办公室**或 **设置 > 虚拟办公室 > 开启虚拟办公室**打开；直接 Web/Linux 不提供同等原生窗口。

- 办公室展示真实主任务、星型/网状成员、工具活动、思考/回复、等待确认和交接状态。
- 默认跟随当前会话，也可选择最近会话并固定观察；布局和角色外观按会话保持稳定。
- 顶部控制在悬停或键盘聚焦时出现，鼠标离开约 1 秒后隐藏。
- 默认置顶；取消置顶后普通窗口可以覆盖它，缩放不会重新置顶。
- 关闭按钮只关闭办公室，主窗口、任务和 daemon 继续运行；菜单与设置开关同步，可再次打开。
- macOS 的功能入口不等于每个版本已完成实机验收，诊断时仍核对平台和安装版本。

## 快捷键、模型与文件

**设置 > 快捷键**或 `Ctrl+/` 打开可搜索目录。macOS 将下表 Ctrl/Alt 对应为 Cmd/Option，
控制台仍使用 Ctrl+反引号。

| 操作 | Windows/Linux |
| --- | --- |
| 当前工作区新建会话 | Ctrl+Alt+N |
| 聚焦主输入框并保留草稿 | Ctrl+Alt+I |
| 显示/隐藏左侧栏、右侧面板 | Ctrl+Alt+B、Ctrl+Alt+E |
| 打开设置 | Ctrl+, |
| 停止当前会话 | Ctrl+Shift+. |
| 前进、后退 | Ctrl+-、Ctrl+Shift+- |
| 增加、降低思维深度 | Ctrl+Alt+>、Ctrl+Alt+< |

思维深度只在模型支持的档位间调整，到边界停止；运行中修改影响后续请求。模型保存、刷新和
进入新对话时会异步同步远端声明，失败保留本地配置；用户明确关闭推理的选择不会被自动打开。

OpenAI 类型模型在 **设置 > 模型 > 新增/编辑 > API 协议**选择 Chat Completions 或 Responses。
旧预设默认 Chat Completions，不按模型名称自动切换。Responses 的 Base URL 模式填写基础地址，
完整端点模式填写完整请求地址；只改 URL 不能代替选择协议。保存前用检测验证连接。

HTML/HTM 预览的浏览器图标在原生浏览器可用时出现，打开保存的本地 `file://` 文件。
取消保存或保存失败不会创建页签；无法访问的本地资源、需要服务端接口的应用仍需相应开发服务器。
长会话先加载最近一页，向上滚动加载更早记录，悬浮向下箭头回到最新内容；运行中箭头可显示三点状态。
