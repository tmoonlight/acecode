## ADDED Requirements

### Requirement: 每个定时任务独立设置会话保留策略
系统 MUST 在任务编辑器和创建工具中支持互斥的自动归档与自动删除选项，以及 1 至 100 的保留数。

#### Scenario: 新建或迁移旧任务
- **WHEN** 用户未选择清理策略
- **THEN** 两个开关均关闭，保留数默认为 3，既有会话保留

#### Scenario: 任务开始运行
- **WHEN** 定时或手动运行已启用清理的任务
- **THEN** 从本任务最近的可见会话起保留指定数量，包含新会话，跳过置顶和已归档会话；仅对超出数量且空闲的会话执行选定操作

#### Scenario: 清理方式生效
- **WHEN** 有符合清理条件的旧会话
- **THEN** 归档模式保留其历史，删除模式连同子会话永久清理，并保护仍有运行中子会话的会话树

#### Scenario: 无效策略
- **WHEN** 两个清理开关同时开启或保留数超出范围
- **THEN** 拒绝保存并返回对应的验证错误

#### Scenario: 会话正在被使用
- **WHEN** 旧会话或待删除的子会话有待处理输入或其他进程持有写租约
- **THEN** 跳过本次清理，在下一次运行时重试；并发提交的输入要么被接受并保留，要么明确返回失败

#### Scenario: 任务更换工作区
- **WHEN** 下一轮任务已切换工作区
- **THEN** 依据每个会话的实际存储位置和对应的置顶列表清理旧记录
