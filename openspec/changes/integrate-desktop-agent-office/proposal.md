## Why

Claude 会话已实现原生像素办公室桌宠，但尚未连接真实 agent。用户已确认以这套桌宠接入单 agent、星状及网状协作，并删除主线中不再需要的“好好工作事务所”独立原型。

## What Changes

- 完整引入原桌宠及未提交的随机布局、扩充家具和自由缩放改进。
- 办公室常驻；按用户最近发送消息的时间提供最多五个主会话的切换入口。
- 办公室提供默认开启的跟随开关；手动切换后固定，重新开启后跟随主窗口。
- 主 agent 完成显示 zzz，收到新任务醒来；子 agent 完成即离座，再次工作时以相同身份及外观返回。
- 真实工具活动、审批、提问、取消、失败、上下文和压缩状态驱动画面；工具图标与聊天界面共用来源。
- 保存按会话稳定的随机布局，完整处理重连、切换、窗口关停和订阅回收。
- 删除 design-prototypes/agent-office 的旧页面及相关过时说明。

## Capabilities

### New Capabilities

- `desktop-agent-office`: 原生桌面办公室、最近五个会话、真实角色生命周期、工具与上下文可视化。

### Modified Capabilities

无；当前主规格目录没有同名能力。

## Impact

涉及原生 Desktop/WebView2、Web 应用级状态适配与图标、会话最近用户消息时间和只读查询、构建注册、相关测试与文档。沿用现有 agent 运行与权限机制。Windows 为当前原生实现，其它平台保持原有桌面行为。只合入本地 master 并提交，不推送或发布版本。
