## Context

动机见 proposal.md。主线已有持久化单会话、星状子任务和网状协作树；旧分支的桌宠由独立 WebView2 窗口及内嵌 Canvas 页面组成，保留 5 套布局、1 个核心位与 7 个组员位、家具与人物变化、鼠标拖动和缩放。原分支 5 个未提交文件是本次导入的权威版本。

## Goals / Non-Goals

**Goals:** 在现有 agent 生命周期之上增加只读可视化；无额外模型请求；后台工作和多会话切换可恢复；窗口异常不影响主界面。

**Non-Goals:** 改造调度策略、从动画反推任务完成、重画美术、新增 macOS/Linux 原生桌宠、推送发布。

## Decisions

### 1. 唯一状态来源与数据流

会话元数据保存最近真实用户消息时间，普通输出、打开会话、元数据修改不改变它。旧会话从持久化消息回填只读查询结果。全局目录提供最近五个未归档主会话，跨工作区按该字段排序；子会话保持归属父办公室。采用独立只读端点和现有全局目录，避免依赖侧栏的更新时间排序或全量历史加载。

Web 应用级控制器读取最近列表及当前办公室快照，持有当前主会话及运行中子会话的引用计数订阅，用真实 WS 增量更新结构化状态。场景快照通过桌面桥送至 DesktopPet，宠物交互通过同一桥返回。主页面隐藏到托盘时继续更新；页面重载和 WS 重连重取快照。显示层不持有 agent 服务或控制权限。

### 2. 选择与跟随

默认跟随主窗口；点击五个会话中的门牌关闭跟随，固定选中。开启跟随后恢复当前主会话。最近名单仅在用户发送消息后更新；跟随查看名单以外会话时临时显示该房间，不改五个门牌的排序。无会话时呈现待命房间和可理解的空态，不启动模拟任务。

### 3. 角色生命周期

主会话始终映射固定核心角色 Maestro，收到真实完成结果后显示 zzz，下一回合醒来。等待审批/回答、压缩、重试、取消与失败独立表达。子 agent 以 session id 为身份，星状和网状统一归属根办公室，保留 agent_path 表达真实层级；成功完成立即离座，再次执行时以同外观返回。取消和失败不冒充完成。工位不足显示额外运行人数并允许进入对应会话查看，空位释放后补位。

### 4. 图标、上下文与随机性

工具名到图标映射为共用纯数据；聊天工具行、子任务和桌宠使用同一 SVG 定义。桥传受控图标数据而非执行脚本或任意 HTML。文件堆复用聊天 token 预算算法，以最近请求上下文用量/窗口大小计算；压缩成功后依实际新用量变薄，未知值不伪造百分比。每个会话的布局和角色外观由稳定身份种子决定。

### 5. 原生与所有权

导入窗口实现并补齐桥与缓存快照。GUI 线程拥有窗口/COM；回调仅持有 weak_ptr 或 lifetime 引用，销毁清理事件、计时器与窗口。控制栏与房间命中区域一起缩放，透明区域继续穿透；保留不抢焦点与已有自由缩放。Web 控制器可显式销毁并释放全部订阅、定时器和在途请求。

## Risks / Trade-offs

- [旧会话缺少最近用户时间] → 基于持久化可见用户消息查找并缓存，禁止用 updated_at 伪装。
- [切换/重连时旧快照覆盖新状态] → 会话身份、控制器代次、事件序号校验；断线显示连接状态并从权威快照恢复。
- [多工作区/子会话结束混淆] → 使用全局目录、实际父关系/agent_path 与真实回合结局，测试同名和跨会话情况。
- [当前 master 有并行脏改动] → 独立 worktree 实施、导入范围审查、合并前保存并比对原工作区改动，仅提交本功能。

## Migration Plan

先记录原分支导入文件校验值，复制到本工作区并登记构建；新增规格、状态和测试；接线、验证 native 与 Web；最后将功能提交合回本地 master，并保留原分支和原工作区的其它改动。
