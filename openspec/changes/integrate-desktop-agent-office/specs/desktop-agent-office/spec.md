## Purpose

将真实单 agent 与多 agent 会话呈现为常驻桌面的像素办公室，让用户在最近五个会话之间切换，并通过角色动作、工具图标和文件厚度观察执行、等待与上下文状态，同时保留原生桌宠交互和可靠恢复能力。

## ADDED Requirements

### Requirement: 常驻桌面办公室

Windows 桌面端 SHALL 显示沿用现有像素美术的透明置顶办公室，保留拖动、自由缩放、大小记忆和透明区域穿透；没有任务时也保持可见。系统 SHALL 移除旧“好好工作事务所”独立原型。

#### Scenario: 启动与空闲
- **WHEN** 桌面端启动且没有运行任务
- **THEN** 办公室可见并显示待命或睡眠状态，不发起演示任务或模型请求

#### Scenario: 缩放与关闭
- **WHEN** 用户缩放窗口、换 DPI 或退出应用
- **THEN** 命中区域与画面一致、大小按逻辑尺寸恢复，退出释放窗口和事件资源

### Requirement: 最近五个会话与跟随

办公室 SHALL 提供跨工作区最近五个未归档主会话，严格按用户最后发送消息时间排序。子会话、后台输出与仅打开会话 SHALL NOT 改变该名单。办公室 SHALL 提供默认打开的跟随开关，手动选择办公室关闭跟随。

#### Scenario: 消息排序
- **WHEN** 第六个主会话收到用户新消息
- **THEN** 该会话进入最近五个列表，最早发送消息的会话退出列表
- **AND** 子 agent 的输出或主会话后续工具调用不挤占名额

#### Scenario: 手动与跟随切换
- **WHEN** 用户手动选择门牌后又切换主窗口会话
- **THEN** 办公室保持手动选中会话
- **AND** 用户打开跟随后显示主窗口当前会话；若其不在最近五个内，临时显示但不重排最近列表

### Requirement: 真实角色状态

办公室 SHALL 适用于单 agent、星状和网状协作；角色身份、动作和气泡来自真实会话状态。主 agent 成功完成 SHALL 保持在座并显示 zzz，新任务开始后醒来。子 agent 成功完成 SHALL 立即离座，后续任务再次入座时保持身份与外观。等待审批、提问、重试、取消、失败 SHALL 独立表达。

#### Scenario: 单 agent 完成与唤醒
- **WHEN** 单 agent 收到真实成功完成结果后开始下一回合
- **THEN** 办公室依次显示 zzz 和工作状态，过程中没有模拟子角色

#### Scenario: 多 agent 与再次执行
- **WHEN** 星状或网状子 agent 完成、随后收到新任务
- **THEN** 角色立即离座，再以相同外观进入所属根会话办公室
- **AND** 等待审批或等待回答不触发成功退场或主角色睡眠

#### Scenario: 工位溢出
- **WHEN** 运行中的子 agent 数量超过七个组员工位
- **THEN** 办公室显示额外人数并保留查看入口，空位释放后可见成员补位

### Requirement: 工具与上下文表达一致

桌宠与聊天工具行 SHALL 使用相同来源的工具图标。每位角色的桌面文件厚度 SHALL 反映真实当前上下文占用比例；压缩成功后根据新的用量变薄，未知用量不得显示伪造比例。

#### Scenario: 工具调用
- **WHEN** agent 开始一个内置工具调用
- **THEN** 聊天与办公室显示一致的工具图标及当前活动

#### Scenario: 上下文压缩
- **WHEN** 上下文占用增长并发生一次成功压缩
- **THEN** 文件堆随真实占用增加，并在压缩后的新用量到达时变薄

### Requirement: 稳定外观与恢复

同一会话的随机布局及同一角色的外观 SHALL 在切换、重连和重启后保持稳定。系统 SHALL 用权威快照恢复状态，拒绝过期响应，不重复播放已处理的消息交接动画；连接失败不得伪装成工作完成。

#### Scenario: 切换与重连
- **WHEN** 用户快速切换办公室且旧请求迟到，或连接断开后重连
- **THEN** 当前办公室只应用对应会话的新快照与事件，角色、状态和文件堆可恢复，原来的订阅被正确释放

#### Scenario: 随机会话布局
- **WHEN** 同一会话重新打开，另一个会话首次打开
- **THEN** 前者恢复相同布局，后者按独立稳定种子选取现有模板及家具
