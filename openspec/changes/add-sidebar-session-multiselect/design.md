# Design

## Context

现有 Sidebar 使用两层 SessionTreeRows、指针捕获拖动和服务端 session-sidebar。分组标题是虚拟节点；真实会话仍有独立 pin、状态、归档入口。全局 DesktopContextMenu 已有同步右键委托，可复用菜单定位和键盘处理。动机见 proposal.md。

## Goals / Non-Goals

**Goals:** 选择与当前打开会话分离；保持普通单击导航；让批量动作复用已有数据入口；批量树布局原子保存。

**Non-Goals:** 跨工作区搬迁会话、任意深度嵌套、选择折叠节点中的隐藏会话、修改子代理 parent_session_id。

## Decisions

1. 提取选择纯函数和 hook，通过 Sidebar 内 context 给行提供状态。以范围加会话 ID 做身份，使用当前渲染行的 DOM 顺序决定范围，避免复刻分页、置顶和分组投影。每次提交后清理不再可见的选择；锚点消失则下一次 Shift 从目标建立选择。
2. 保留点击打开会话；修饰键选择只改变集合。拖动已选项不缩减集合，拖动未选项只操作该项。分组标题保留原单组拖动与折叠，不进入多选。Escape、pointercancel、窗口失焦均结束拖动，点击空白清空选择。
3. 普通树请求增加 sources 数组，旧 source 保持兼容。领域层在副本上验证和执行整批移动，成功后替换并原子写布局。after 使用反向插入以保持顺序；拖入独立定时行创建手工组后，后续源使用新组键。
4. 置顶排序复用全局顺序 API 和逐 scope 顺序保存；保存期间禁止重入。批量置顶/归档顺序执行，复用已建立的单项操作，单项支持静默反馈和返回成功值；最终一条结果反馈，失败行保留。已读/未读复用现有连接状态命令。
5. 右键通过现有菜单委托构造操作快照和自定义菜单项，不修改通用菜单识别优先级。混合 pin/read 状态给出全部置顶/全部标记未读，同时提供取消置顶/标记已读；全同态优先显示反向动作。
6. 移除整块分组底色，子项缩进 18px 并以低对比度细线连接。按 2026-10-24 用户参考图，竖线从首个子项顶部连续贯穿，只在最后一个子项中线处向右圆角收尾，中间子项不画横向分支，父项箭头下不另画接线。连接线使用独立装饰元素，避免拖动插入线占用行伪元素时造成断线；末尾短横线长度不随未读或运行状态改变。选择行单独高亮。拖动预览随指针平移、最多显示三条和数量，复用现有图标与主题变量，兼容旧 WebView。

## Risks / Trade-offs

- 轮询覆盖批量结果 → 保存期间阻止旧列表应用，沿用树请求代次。
- 状态命令为既有异步连接协议 → 保留原乐观状态与服务端 ack，不另造持久化协议。
- 选择跨范围可执行批量菜单但不能搬迁数据 → 非法普通树拖放不显示接收高亮且不提交，置顶排序仍可跨范围。
- 工作区已有无关修改 → 只修改功能相关文件；已有脏文件内只追加对应 API 段落。

## Migration Plan

布局文件格式不变，接口兼容旧 source。回滚前端仍可读批量后的普通布局；需要构建并重启 Desktop 才能加载新内嵌资源，本轮源码和浏览器验证不代表已安装程序更新。
