## Context

侧栏已有布局规范化函数和版本化缓存键。桌面引导通过认证的 daemon 接口读写用户数据目录的 `state.json`，嵌入式 WebView 和 Edge 兼容模式都能使用这条路径。

## Decisions

- 复用桌面引导的存储方式，将 `order` 和 `pinned` 作为一个快照原子更新。前端继续负责识别已注册的扩展、移除失效项、追加新项。
- 桌面优先恢复持久记录。仅在记录缺失时从当前来源导入有效的旧布局，多个窗口启动时，迁移写入只在记录缺失时生效。有意取消全部固定项也是有效记录。
- 普通浏览器继续使用现有缓存键。桌面上的本地缓存用于快速展示，服务端读写与用户操作协调，避免恢复或较早的保存覆盖最新编辑。关闭自定义弹框时确认最后一次保存，失败后可重试。
