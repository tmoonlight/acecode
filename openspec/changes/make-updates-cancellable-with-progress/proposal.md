## 背景

图形界面发起升级后，前端请求与升级下载均受固定 30 秒超时限制，大包或慢速网络会被误判为失败；同时用户无法主动停止尚未进入文件替换阶段的升级，顶部入口也不能直观展示当前进度。

## 变更内容

- 取消图形界面升级启动请求以及升级清单、安装包下载的固定 30 秒超时限制。
- 为升级任务增加可取消状态与取消接口，允许用户在下载和安装准备阶段安全取消；真正开始替换程序文件后不再接受取消。
- 在升级对话框中提供取消操作，并明确展示取消中、已取消及不可取消阶段。
- 保持顶部“更新中”按钮的尺寸与圆角形状不变，以主色填充表示进度；填充区文字使用白色，未填充区文字使用主色。
- 2026-10-07 位置调整：将上述更新入口整体移到侧边栏底部、问题反馈按钮左侧；顶部不再显示更新按钮。

## 能力

### 新增能力

无。

### 修改能力

- `self-upgrade`：升级任务不再因固定 30 秒限制失败，并支持在安全阶段由用户取消，同时向图形界面公开进度与可取消状态。

## 影响范围

- 升级下载与执行逻辑：`src/upgrade/`
- Web 更新任务 API 与状态模型：`src/web/`
- Web 更新对话框、顶部栏与轮询逻辑：`web/src/`
- 升级 HTTP、Web 路由及前端行为测试
