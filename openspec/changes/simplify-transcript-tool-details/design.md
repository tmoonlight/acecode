# Design

## Context

见 proposal.md。ToolBlock 直接显示 summary.verb 和 metrics；兜底把所有参数值拼成 object。历史投影仅为 Shell 恢复参数。ActivityLine 的箭头已支持 hover / focus 显示，应保留。

## Goals / Non-Goals

统一显示层的工具身份、对象和详情规则，原始输出、工具协议和持久化记录保持完整。实现可随语言切换重新计算，避免在 reducer 中缓存翻译。保留问答、源码、diff、附件等专用内容。

## Decisions

- 使用集中、可枚举的内置工具中英文词条，附常用协议别名；以原始工具身份选择名称，不依赖英文过去式。无工具身份的旧摘要仅做有依据的兼容。
- 纯展示函数提取单个对象和必要字段：文件路径使用现有 basenameForPath，搜索使用 pattern，Shell 使用命令预览；不枚举全部请求值。输出参数或代码正文不再抄到参数表。
- 历史投影为所有匹配调用恢复 name / args，并单独提供 resultOutput；保留原有 output 和 coveredItems，避免影响存储、复制之外的消费者或旧数据诊断。
- 普通卡片内部顶部放完整路径、必要参数和统计；diff / 新文件源码继续原渲染器，避免嵌套卡片。无正文但有字段仍能展开。
- Shell 使用已有输出卡的 transcript 变体，取消内部 Shell 标题和重复命令参数区。主行可完整显示单行命令时卡片不再重复；多行或因宽度截断时，仅在卡片一处保留完整命令。复制始终保留完整命令与结果。
- ActivityLine 增加可选分隔符，工具传入本地化冒号，其余使用者保留现状；保持箭头 CSS、宽度和旋转规则。

## Risks / Trade-offs

- 旧记录缺少参数 → 有真实摘要才恢复对象，不推测请求范围或把上限解释成结果数量。
- 条件注册工具易遗漏 → 测试对照后端工具定义及动态工具家族，确保两种语言均有名称。
- 长名称与窄屏 → 使用真实组件验证省略、换行和 hover / focus；不改变固定主行高度。
- 输出本身包含重复文本 → 保留原始输出，去重仅针对界面生成的字段和包装，不删除用户内容。

## Migration Plan

先增加词条和展示逻辑，再接入工具行与历史投影，完成定向测试、全量 Web 测试、构建、双语宽窄屏浏览器验证。无需数据迁移；Desktop 安装版需重新构建加载前端，本次不自动启动或替换安装版。
