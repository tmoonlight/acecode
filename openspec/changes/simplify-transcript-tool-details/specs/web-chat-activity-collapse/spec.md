## ADDED Requirements

### Requirement: 内置工具使用本地化的紧凑主行
Web 和 Desktop 的工具主行 SHALL 使用随界面语言切换的可读动作名称与冒号分隔的最小必要对象；所有内置工具（包括条件注册工具）均须覆盖。文件对象 MUST 仅显示文件名；主行不得展示无标签参数或统计。

#### Scenario: 同一工具的生命周期与语言切换
- **WHEN** 读取文件处于运行、成功或失败状态，或从历史恢复
- **THEN** 中文界面显示「读取文件：index.vue」，英文界面显示「Read File: index.vue」
- **AND** 切换语言直接更新显示，不写入或修改原始 transcript

#### Scenario: 搜索限制不冒充结果数量
- **WHEN** 搜索内容包含 pattern、include_pattern 和 head_limit=50
- **THEN** 主行仅显示动作和搜索词，展开后显示文件过滤条件和最多 50 条的限制

### Requirement: 工具展开卡片补齐必要信息并避免重复
展开卡片 SHALL 展示完整路径、必要请求条件、统计与结果，省略空值和冗余默认信息；界面生成的同一信息 MUST 仅展示一次，保留原始输出和复制内容。统计 SHALL 位于卡片内；只有统计或参数时也须可展开。

#### Scenario: 读取文件详情
- **WHEN** 用户展开读取文件
- **THEN** 卡片顶部显示完整路径和可用的读取行数、大小、编码、换行信息，下方显示文件内容
- **AND** 不额外显示重复的工具名称或整张请求 JSON 表

#### Scenario: Shell 不重复命令
- **WHEN** 单行命令在主行完整可见且用户展开
- **THEN** 卡片显示统计和输出，不增加 Shell 标题或重复命令字段
- **AND** 多行或主行被截断的命令在卡片中仅完整展示一次，复制仍包含完整命令和输出

#### Scenario: 历史调用详情
- **WHEN** 旧记录的请求与结果能够按调用标识配对
- **THEN** 展示层恢复工具身份和参数，结果区不再重复请求包装，原始记录保持不变

### Requirement: 工具箭头保持既有交互设计
工具行展开箭头 SHALL 保持既有图标、位置、尺寸与旋转规则，默认隐藏，在 hover 或键盘焦点进入时显示。

#### Scenario: 展开前后的箭头显隐
- **WHEN** 工具行处于展开或收起状态且既无 hover 也无键盘焦点
- **THEN** 箭头不可见但保留占位；hover 或焦点进入后可见，点击和 Enter / Space 均可切换详情
