## ADDED Requirements

### Requirement: 窄栏按优先级分配空间
会话栏位 MUST 根据实际可用宽度省略次要信息，保留操作入口、完整的可访问名称和正常的聊天正文换行。

#### Scenario: 窄标题栏
- **WHEN** 顶部操作和目录名、会话标题无法同时完整显示
- **THEN** 操作保持可用，标题先省略，过长目录名单行省略；重命名仍能输入

#### Scenario: 输入框局部宽度不足
- **WHEN** 右侧面板或窗口缩小使工具栏无法容纳当前控件
- **THEN** 收起次要标签和指标，模型名可单行省略；最小控件仍放不下时分行，添加、发送或停止和设置入口可操作；加宽后恢复

#### Scenario: 待办和变更同时出现
- **WHEN** 窄聊天栏同时显示待办进度和文件变更
- **THEN** 统计细节依次让位，摘要不覆盖查看和关闭按钮；单独显示待办时仍可读取步数，聊天消息继续换行
