## 为什么

会话首句触发自动命名时，顶部和侧边栏直接替换文字，用户容易错过标题变化。增加快速打字与短暂光标，让这次更新清楚可见。

## 变更内容

- 同一会话的显示标题更新时，顶部和侧边栏同步逐字呈现新标题，结束立即移除光标。
- 初次显示、切换会话、重复刷新相同标题不重播；连续改名直接呈现最新一轮。
- 保留侧边栏长标题悬停滚动、标题编辑与既有布局；遵循减少动态效果偏好。

## 能力

### 新增能力

- `session-title-transition`：会话显示标题变更时的同步打字反馈。

### 修改能力

无。

## 影响

影响 Web 与 Desktop 共用的标题栏、侧边栏及展示辅助模块。标题生成、存储与通信协议保持原有语义，不引入依赖。
