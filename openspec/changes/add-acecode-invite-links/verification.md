## 两个隔离 daemon 与桌面 Web 界面

两个 daemon 分别使用临时 USERPROFILE，模型是同机 OpenAI-compatible 测试服务，没有真实 API key 或模型费用。Edge 中完成：

1. A 顶栏分享按钮在属性左侧，生成只读链接。
2. B 输入框粘贴，确认前不连接；取消后原文恢复。
3. B 连接后看到历史，没有提问入口。
4. A 新消息实时出现在 B；A 撤销后 B 显示断开。
5. 重新生成可交互链接，B 独立提问并得到回答；A 分享详情显示提问记录，主会话没有访客问题。
6. 独立桌面界面复查提出的生成期间权限切换竞态已修复，复查结论为通过。

测试地址：A `http://127.0.0.1:54406`，B `http://127.0.0.1:54954`。仅在本次临时进程仍运行时有效。最终交接以回复中的地址为准。
