## Context

参考图确立浅绿地砖、奶油墙面、等距投影、深色像素轮廓和蓝色办公椅的视觉方向。用户确认先交付独立页面，双击 index.html 即可运行。

## Goals / Non-Goals

目标：代码绘图、素材复用、可交互、离线运行、低空闲开销、可供未来状态接入的清晰边界。
非目标：生产集成、真实模型请求、远程资源下载、游戏经济系统。

## Decisions

- 原生 HTML/CSS 与顺序加载的普通 JS，共用 PixelOffice 命名空间，兼容 file 协议。
- assets.js 负责整数坐标像素光栅、共享家具图集、人物模板换色和少量动画帧；实例只存配置和位置。
- simulation.js 使用显式 dt 驱动状态与依赖任务；走路沿定义通道，团队成员数据不包含展示 DOM。
- renderer.js 缓存房间背景，按地面深度排序家具和人物；同一资源同时用于场景、头像和图鉴。
- app.js 是唯一交互适配层，负责选择、派发、缩放、暂停和速度。隐藏页面停止动画调度；暂停时只在交互后重绘。prefers-reduced-motion 默认暂停。
- CSS 是该独立原型的局部视觉系统，不注入主应用；窄屏将成员面板移到场景下方。

## Risks / Trade-offs

程序绘制需要浏览器截图核对轮廓、遮挡和图块拼接。有限缓存避免每帧重复光栅化；Canvas 本身不能提供键盘节点，成员列表用原生按钮作为等价操作入口。

## Validation

离线 file 页面与本地 HTTP 页面；任务完成依赖、重复派发保护、暂停/恢复、倍速、选择、缩放；桌面及窄屏截图；浏览器错误与外部网络请求；严格 OpenSpec 校验。按仓库要求运行 web 测试和构建，分别报告基线失败。
