## ADDED Requirements

### Requirement: 独立代码绘制的办公室
系统 SHALL 提供无需安装依赖、无需联网即可打开的独立页面，用程序化共享资源呈现等距像素房间、家具和六位团队成员。

#### Scenario: 离线打开
- **WHEN** 用户用浏览器打开 index.html
- **THEN** 办公室完整呈现且不发起外部资源请求
- **AND** 模拟数据标识可见

### Requirement: 共享素材与受控渲染
系统 SHALL 复用图块和人物模板，缓存静态房间与素材，并在暂停或页面隐藏时停止连续动画调度。

#### Scenario: 资源复用
- **WHEN** 场景、侧栏头像与图鉴显示相同成员或家具
- **THEN** 它们使用同一资源定义与缓存

#### Scenario: 暂停
- **WHEN** 用户暂停演示
- **THEN** 模拟时间、任务进度和人物动作保持不变
- **AND** 选择和缩放仍可操作

### Requirement: 可交互的团队模拟
系统 SHALL 提供成员选择、任务派发、倍速和缩放，并以结构化状态呈现任务依赖和进度。

#### Scenario: 派发任务
- **WHEN** 用户派发新任务
- **THEN** 成员按任务依赖推进工作并最终完成项目
- **AND** 同一项目执行期间不能重复派发

#### Scenario: 键盘与窄屏
- **WHEN** 用户用键盘或窄屏浏览器访问
- **THEN** 所有操作均有可聚焦的原生控件且页面无横向溢出
