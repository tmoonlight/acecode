## Context

透明窗口保持 344 × 252 的基准尺寸，为上方宽会话卡片留出空间。精灵逐帧 alpha 横条已用于原生命中区域，但悬停时被整个精灵画布外框取代；页面内部悬停也使用该外框。

## Goals / Non-Goals

目标：本体激活区贴近实际轮廓；把手位于宠物左上角；气泡大小及点击区域保持。范围不含办公室布局、宠物尺寸、会话卡片样式与行为。

## Decisions

1. 始终上报 alpha 轮廓横条，保留既有小幅动作边距。悬停稳定性仅用鼠标进入位置附近的小矩形维持，避免动画跳动触发反复进出。
2. 页面内悬停判断复用本体轮廓，不使用精灵外框。换角色、离开和拖动结束后避免遗留悬停区域。
3. 缩放把手保持 16 CSS 像素，位置来自可见轮廓左上角；窗口缩放时重算 CSS 坐标。贴边时夹到窗口内。
4. overlay 消息添加可选 `grip` 矩形。共享解析器验证并纳入窗口区域，macOS 保存并用于原生缩放光标；办公室继续使用既有固定坐标。
5. `rect` 仍独立上报会话卡片外框，保持宽度与绘制阴影留白；不缩窄整个窗口。

## Risks / Trade-offs

轮廓按有限数量横条近似，保留动画所需的小边距；快速变换姿态时把手位置随可见范围更新。macOS 本机运行需在 macOS 后补，Windows 构建与共享页面可在当前机器检查。

## Migration Plan

无需数据迁移。旧的办公室页面不发送 `grip`，原生宿主保留办公室固定把手命中。
