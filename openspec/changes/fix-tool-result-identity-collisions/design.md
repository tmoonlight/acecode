## Context

见 proposal.md。ToolResultCommitter 从整个历史重建按 ID 索引的替换状态；历史请求中的 ID 修复发生得太晚，无法保护执行和结果提交。现有输出文件名只含提供者 ID。

## Goals / Non-Goals

**Goals:** 实际执行的每次调用拥有可区分身份；真实输出、保存文件和预览一致；保留既有成功标记、附件和摘要。

**Non-Goals:** 不恢复已被覆盖而未留存的原始输出，不改原始会话文件，不调整模型结束规则，不替换或重启正在工作的实例。

## Decisions

1. ConversationHistory 登记已观察的调用、结果和替换记录 ID。执行前保留未冲突的 ID，对空值和重复值生成新的 UUID ID。登记在该对象生命周期内保留，包括压缩、历史替换与清空，避免旧调用标识被再次分配；恢复消息也登记。只修改新响应，不修改旧历史。逐个模型步骤在错误处理之后、轨迹记录与执行之前调用，避免失败重试执行工具。
2. 输出文件采用清理后的 ID 加 UUID 文件名，每次持久化写入新文件。与只覆盖旧文件相比，旧预览引用继续正确；已经是 persisted-output 的结果沿用已有引用，不重复写入。
3. 对旧历史重复 tool_call_id，不应用只能按 ID 匹配的替换记录。保留每条原有正文，不凭旧预览猜测丢失的数据。唯一 ID 的恢复行为保持。
4. 回归使用无害固定文本和模拟工具，验证模型实际收到的下一轮结果、文件内容、事件配对以及会话恢复；不重放现场业务命令。

## Risks / Trade-offs

- 已污染内容无法可靠恢复 → 保留原记录并说明限制，修复保证后续执行结果正确。
- 新文件名改变内部约定 → 测试与使用方从预览中的路径读取，旧路径仍可访问。
- 记录已用 ID 增加少量内存 → 仅保存 ID 字符串，不保留旧正文。

## Migration Plan

构建新的 Windows 可执行文件并验证；使用新构建启动后生效。不修改现有配置和原始会话。回退代码不删除已生成文件。运行实例切换与源码验证分别报告。
