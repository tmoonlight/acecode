## Context

ChatView 已有尾部跟随状态机、活动展开锚定、滚动与尺寸变化测量。现有自动跟随采用 80px 近底阈值。

## Goals / Non-Goals

目标：提供消息区底部中央的返回按钮，点击到达底部并恢复跟随，兼容窄窗口和主题。
非目标：修改侧聊、文件预览或现有滚动条行为。

## Decisions

- 显示以真实滚动距离大于 2px 为准；滚动高度、视口高度的整数取整与缩放后的滚动位置叠加时，到底后的剩余距离可能超过 1px。使用独立的 2px 容差，不复用 80px 跟随阈值，以免距离底部仍有内容时缺失入口。
- 接入现有合帧测量，以及内容、视口尺寸变化；短会话和到底时隐藏。
- 每次受状态保护的程序滚动后立即刷新按钮显隐，保证浏览器已经到底、没有产生额外 scroll 事件时也能更新；普通滚动和尺寸变化仍复用现有合帧测量。
- 新增 `jump_to_tail` 状态动作。点击取消活动展开锚定，复用受状态保护的尾部滚动调度，立即滚到底；无需额外动画。
- 36px 圆形按钮使用真实 SVG、`bg-surface`、`text-fg`、`ace-shadow-lg` 和可见键盘焦点，悬浮在消息区而非滚动内容中。
- 以消息栏自身为定位容器，距底至少 12px；存在审查浮层时使用已测量的 `changeDockBottomPadding` 上移。
- 运行中复用 ChatView 的 `status === 'running'`（实时 busy 或已恢复的 running 状态），不另设计时器或推断文本。按钮只替换内部图标：三个 4px 圆点按从左到右的延迟依次上跳 3px，每轮各跳一次；空闲、完成、报错或确认中断后恢复箭头。
- 三点继承按钮主题前景色，保持 18px 图标占位与 36px 点击区域。运行中提示为“运行中”，可访问名称保持“滚动到底部”，图案对辅助技术隐藏；到底时整个按钮照常隐藏。
- 2026-10-05 用户反馈三点完全静止：Windows 的 `SPI_GETCLIENTAREAANIMATION` 为 false，当前客户端实际提供的样式在 `prefers-reduced-motion: reduce` 下使用 `animation:none`。本次覆盖静态三点的旧约定：作为运行状态提示，减少动态效果时仅将跳动幅度从 3px 降为 1.5px，不完全停掉，不更改系统设置。三点每个占据周期的三分之一，避免原版一半周期完全静止的间歇。
- 动画验证除关键帧时间采样外，必须观察至少两个完整周期的真实时间变化，覆盖系统默认、no-preference 与 reduce；不得仅用手动设置 animation.currentTime 的结果宣称动画会自行运行。

## Risks / Trade-offs

- 查看历史内容期间的新消息不得强制回到底部；按钮只观察尺寸，点击才恢复跟随。
- 现有工作区有其他未提交修改，文案目录更新必须保留它们。

## Validation

运行滚动定向测试、完整 `pnpm test`、`pnpm build`、OpenSpec 严格校验和差异检查；浏览器检查显示/隐藏、点击后跟随、尺寸变化、窄屏与阴影。

2026-10-04 回归：Edge 在 150% 设备比例、90% 页面缩放及小数内容/视口高度下，真实 ChatView 到底后仍报告约 1.407px 的剩余距离；原 1px 判断使按钮持续显示，重复点击也不会消失。补充可重复执行的真实 ChatView 浏览器检查，覆盖缩放误差、手动返回、点击、流式增长和会话切换。
