## Why

Skill 扫描目录目前大多内置，用户无法在设置中统一增删或调整优先级；技能页也缺少跳转入口。

## What Changes

- 增加 `skills.scan_paths` 有序路径列表，未配置时保持旧扫描规则，显式空列表关闭普通目录扫描。
- 配置页增加多行路径编辑、保存及恢复默认；技能说明旁增加可定位到该配置的链接。
- 保存后更新全局与已有会话 registry，保持专家包目录优先及现有启停策略。
- 技能列表只展示实际扫描到的技能，删除文件或移出扫描范围后不再因禁用记录补回幽灵条目；保留禁用偏好。
- 技能设置增加分页，全局与各工作区分别分页，共用每页 20/50/100 条选择，默认 50，仅渲染当前页卡片。

## Impact

涉及配置序列化、共享技能目录解析、Web 设置 API、会话 registry 刷新、设置页及搜索索引；同步 API 文档和回归测试。默认安装位置不变，无发布副作用。
