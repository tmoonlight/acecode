## Why

ACECode 自动生成的会话、日志、附件和导出文件混用连字符与下划线。统一新名称使用 `_`，同时确保已有会话和日志仍可读取、恢复和收集。

## What Changes

- 新会话 ID 使用 `YYYYMMDD_HHMMSS_xxxx`；列表、恢复、诊断同时识别新旧格式。
- 自动生成的运行数据、日志、反馈、导出、临时文件和备份名称统一使用下划线分隔。
- 固定持久化路径采用旧路径兼容解析；已有资源继续使用实际路径，不批量重命名。
- 用户确认只调整自动生成的运行数据。标准协议标识、外部工具约定的文件名和用户明确提供的路径保留其语义；发布包与 AI 自主创建的工程文件不在本次范围。

## Capabilities

### New Capabilities

- `runtime-file-naming`: 新生成运行数据的下划线命名及旧名称兼容。

### Modified Capabilities

- `session-storage`: 新会话 ID 的格式和新旧数据同时发现、恢复。

## Impact

涉及 base 路径与日志工具、session 存储与导出、工具输出、反馈收集、升级诊断和对应开发启动器、测试及文档。无数据批量迁移，不改变 HTTP 路由、第三方 UUID 标准或既有会话标识。
