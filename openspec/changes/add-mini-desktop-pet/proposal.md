# Proposal

## Why

用户需要一个名为 `mini` 的桌面宠物，以提供的 Codex 截图为视觉依据，用紧凑导航条代替角色动画，直接输入文字或录音并在后台创建任务，无需切换到主界面，同时查看运行中和待处理的会话动态。

## What Changes

- 在设置与原生右键菜单中增加 `mini`，沿用现有宠物选择偏好。mini 默认使用 1 倍逻辑缩放，并将自己的缩放保存到 `mini-settings.json`，不继承角色宠物的旧缩放。
- 新增透明背景的白色胶囊导航条：输入、录音和任务计数。控件尺寸取自主会话发送按钮的实测值，默认 28 个逻辑像素；导航为三个控件宽、一个控件高，录音态为两个控件宽。计数包含运行中及等待/未读任务。
- mini 自带单行输入胶囊、附件和发送按钮；发送按钮共用主会话的纸飞机图标、主题/禁用颜色及尺寸，并处理两个渲染器的像素比换算。录音时显示紧凑的输入/停止胶囊，停止后自动识别并发送。文字和语音均通过现有 API 创建会话并排队执行，不导航到主编辑器或激活主窗口。
- 会话动态共用经典宠物的 `PetActivityCards` 渲染器、样式、正文字体、状态图标和打开/停止/已读操作。展开时透明原生窗口临时覆盖所在显示器工作区，保留原工具条锚点；气泡默认向下、空间不足时向上，并限制在工作区内。无可见滚动条，溢出内容仍可用滚轮和键盘访问，空白区域保持点击穿透。
- 文字草稿和附件独立保留；语音发送失败提供独立的转写重试/取消，重试不携带文字草稿附件。附件上限为 10 个、总计 25MiB，通过分块桥接传输，并在小窗口内滚动显示。
- 复用现有会话快照、打开会话、拖动、缩放和右键菜单；已接受任务即时显示，并与后续快照去重。拖动、缩放、调整大小等操作先恢复紧凑窗口。胶囊阴影随窗口缩放，气泡保留共享样式，原生绘制区域包含各自阴影边缘。mini 不使用动画图集或贴边偷看。

## Capabilities

### New Capabilities

- `desktop-mini-navigation`: mini 导航宠物的选择、独立文字/语音后台任务、会话动态和窗口交互。

### Modified Capabilities

无。

## Impact

涉及桌宠资源打包、Windows/macOS 宿主、桌宠设置、共享会话按钮外观、经典宠物气泡渲染器、主渲染器中的后台任务/录音控制器和测试；复用现有任务、附件和语音 API，不增加网络依赖或 daemon API。mini 输入时只为桌宠授予键盘焦点；取消或关闭录音后不允许迟到的转写创建任务。
