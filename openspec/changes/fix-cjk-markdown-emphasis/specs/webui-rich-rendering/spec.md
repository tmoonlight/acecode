## ADDED Requirements

### Requirement: 中日韩文字相邻的强调兼容

WebUI 的共享 Markdown 展示 SHALL 识别中日韩文字及标点相邻的星号加粗、星号斜体和删除线，无需用户在这些标记外额外插入空格。完整内容、行内内容与流式分块展示 MUST 使用一致的强调规则，保留已有可正确解析的标点边界及下划线强调。代码、显式转义的星号和原始会话内容 MUST 保持原有语义，HTML 转义与链接限制 MUST 继续生效。

#### Scenario: 全角冒号后紧接中文
- **WHEN** 内容为 `**建议：**共享` 或列表项 `- **同会话消息排序：**异步处理`
- **THEN** 标签连同全角冒号显示为加粗，后续文字正常显示，强调星号不显示

#### Scenario: 保留已有混合标点写法
- **WHEN** 内容为 `提示：**(可选)**`、`结果：**"通过"**` 或 `中文，__重点__。`
- **THEN** 原有加粗范围保持正确，不因中文兼容规则而退化为星号或下划线

#### Scenario: 中日韩强调与删除线
- **WHEN** 内容为 `*注意：*继续`、`前文**（重点）**后文`、`**注意。**続き`、`**주의。**다음` 或 `~~旧值：~~新值`
- **THEN** 对应范围分别显示为斜体、加粗或删除线

#### Scenario: 原文与字面语义保持
- **WHEN** 相同文字出现在行内代码、围栏代码、显式转义文本或含原始 HTML 的内容中
- **THEN** 代码和转义星号保持字面显示，原始 HTML 仍转义，持久化与复制的源文本不变

#### Scenario: 流式补齐强调标记
- **WHEN** 流式消息从未闭合强调逐步追加到 `**建议：**共享`
- **THEN** 已闭合强调正确显示，分块 HTML 拼接与完整渲染相同，先前完成段落不变
