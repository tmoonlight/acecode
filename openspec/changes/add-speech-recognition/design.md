## Context

共享输入框为 InputBar + RichComposer + ComposerSessionControls，Slate 已提供跟随编辑的异步 rangeRef 插入机制。设置工具页以独立可折叠配置卡组织。配置保存沿用 mutate_config，HTTP 客户端沿用 cpr。现有工作区有归档相关脏文件，必须保留。

## Goals / Non-Goals

- 完整交付设置、录音、后端转发、文本回填及 HTTP 内网使用。
- 支持 SenseVoice 自定义接口、OpenAI 兼容音频接口、whisper.cpp；单个当前生效配置可以切换协议和模型。
- 不捆绑或启动模型服务，不实现流式逐字识别、TTS 或 TUI 麦克风录音。
- 不通过关闭浏览器安全设置来支持远程 HTTP 页面麦克风；Desktop/localhost 采集与内网 HTTP 识别相互独立。

## Decisions

1. 配置 speech_recognition 默认 disabled，协议 sensevoice，服务地址空；可选 API Key，OpenAI 协议必须填写模型。地址允许 HTTP、HTTPS 和显式端口，保留 TLS 正常验证，不影响其他模块原有 HTTPS 策略。
2. 设置卡位于工具页，不设独立保存按钮；开关/选项立即自动保存，文本和数字输入在失焦、Enter、收起或离开时提交。连接级 store 串行排空保存队列，保留请求期间的新编辑，重新打开等待保存队列后再读取。失败保留草稿并提供重试；测试连接等待自动保存成功。当前输入框订阅不含密钥的可用性信息并立即更新。
3. Web Audio 采集单声道 PCM，停止后重采样并编码 16 kHz PCM16 WAV；波形取真实音频能量。默认录音上限 60 秒、请求超时 120 秒，设置中可调整；服务仍可施加自己的限制。
4. 前端仅向已鉴权的 ACECode API 上传 WAV。后端按协议映射 multipart 字段和路径，使用有界响应、明确错误码、禁止重定向和请求取消。音频仅驻留请求内存，不落盘或写日志。
5. 输入框以会话身份和请求代次约束录音与结果，复用 Slate 异步插入位置；开始录音时保留草稿和标签，取消不回滚用户自行编辑的内容。停止不提交，发送成功后走现有提交/排队逻辑，识别失败和空结果不提交。
6. 同时只允许一份客户端录音；后端限制并发转写避免堆积。取消接口以请求 ID 标识活动调用。外部识别服务是否真正中止推理由服务自己决定，ACECode 不接受已取消结果。
7. Mac Desktop 添加麦克风用途说明；检查各 Desktop WebView 权限入口，保持仅主页面用户触发采集。Windows 本地编译和浏览器验证作为当前可执行验收，不将其宣称为 Mac/Linux 真机通过。

## Risks / Trade-offs

- 麦克风设备属于浏览器所在电脑，本地偏好与后端识别服务配置分离；使用共享连接无关的本机偏好 store。设备列表仅在显式右键菜单时请求，必要时申请麦克风权限以获取真实设备名称，临时授权流立即释放。
- 默认 Ctrl+D 通过现有快捷键目录、偏好和事件分发接入；仅可用输入框接管。按住模式默认关闭，开启后鼠标/快捷键松开即停止；授权未完成就松开时取消，避免迟到授权后继续采集。
- 原工具栏保持布局占位，录音栏绝对定位覆盖其区域，使用相同内边距和高度，不再用不同高度的组件替换布局。

- 自定义 SenseVoice 不接收按请求选择模型；该协议使用服务端已加载模型，模型输入仅对需要它的协议开放。
- HTTP 内网地址由用户配置；麦克风安全上下文由客户端环境决定，配置端口不能解除远程 HTTP 页面的限制。
- 多会话、权限请求和网络响应可能乱序，状态机测试覆盖取消、迟到响应、停止/发送重复点击及配置变化。
- 真实测试使用独立临时测试配置/服务，避免修改用户现有模型或运行中会话。

## Validation

麦克风右键必须通过已有 `DesktopContextMenu` 委托协议接管捕获阶段的事件，按按钮实例确认归属；不能仅依赖按钮冒泡阶段的 `onContextMenu`。打开设备菜单时关闭已有通用菜单及延迟打开任务，编辑器区域继续使用复制/粘贴等通用动作。浏览器回归必须同时挂载真实全局菜单，验证按钮图标、空白区域和菜单切换。

配置解析/持久化、HTTP 参数映射与错误解析的 C++ 测试；录音状态机、WAV、配置同步的 JS 测试；pnpm test/build；Windows 定向构建和后端 HTTP 实测；浏览器检查主题、入口可见性、录音/停止/取消/发送及草稿隔离。最终审查原有脏改动仍保留。
