## ADDED Requirements

### Requirement: 网页链接点击打开系统浏览器
聊天区渲染出的任何 `http`/`https` 链接，用户左键点击时，TUI 应（SHALL）用系统默认浏览器打开，走与本地文件链接相同的 link-region 命中检测路径。打开为尽力而为、不得致命失败。

#### Scenario: 点击网页链接打开浏览器
- **当** 用户左键点击聊天区中渲染出的 `http`/`https` 链接
- **则** 该 URL 由系统默认浏览器打开（macOS 用 `open`、Linux 用 `xdg-open`、Windows 用 `start`）

#### Scenario: 本地文件链接不受影响
- **当** 用户左键点击本地文件路径链接
- **则** 系统文件管理器在对应路径打开，行为与现状一致

#### Scenario: 打开失败有提示、不致命
- **当** 浏览器启动命令失败（非零退出或 exec 错误）
- **则** 状态栏提示无法打开该链接，TUI 继续运行

#### Scenario: 非链接文本不受影响
- **当** 用户点击不属于任何 link region 的文本
- **则** 走现有的选中文本/兜底行为，不打开浏览器

### Requirement: 伪装 URL 的显示文字在渲染期被中和
当 markdown 链接的显示文字呈 URL 形状、但其 host 与链接目标 host 不符时，TUI 应（SHALL）将该链接降级为纯文本（无链接样式、不进可点击区域）。显示文字为普通标签、或 URL 形文字的 host 与目标一致（含省略 scheme 或截断路径的形式）的链接应保持可点击。比较应（SHALL）仅限域名。

#### Scenario: 伪装 host 被降级
- **当** 链接显示为 `github.com/foo/bar`，但其目标 host 为 `phish.example.com`
- **则** 按纯文本渲染：无链接色、无下划线、无点击行为

#### Scenario: 命名链接保持可点击
- **当** 链接显示为"安装指南"，目标为任意 URL
- **则** 保持可点击并保留链接样式

#### Scenario: 省略 scheme 且 host 一致的文字保持可点击
- **当** 链接显示为 `github.com/foo`，目标为 `https://github.com/foo/...`
- **则** 因 host 一致而保持可点击

#### Scenario: 畸形文字按不匹配处理
- **当** URL 形状的显示文字无法解析出 host（非 ASCII 或畸形）
- **则** 该链接降级为纯文本

### Requirement: 支持的终端发射 OSC 8 原生超链接
检测到 OSC 8 支持时，TUI 应（SHALL）在渲染出的链接 span 周围发射终端原生超链接（OSC 8 开/关对），使终端自身提供 Cmd/Ctrl+点击、悬停、右键打开/复制能力。发射应（SHALL）在每行行尾关闭超链接；同一链接的相邻格子不应（SHALL NOT）重复发射；未检测到支持的终端上应完全不发射。

#### Scenario: 链接 span 被 OSC 8 包裹
- **当** 链接 span 在检测到 OSC 8 支持的终端上渲染
- **则** 输出字节流在 span 文本前含带真实 URL 的 OSC 8 开序列、其后含关序列

#### Scenario: 行边界总是关闭
- **当** 链接 span 跨输出行换行
- **则** 每行在行尾关闭其超链接，下一行重新打开

#### Scenario: 同一链接的相邻格子不重复发射
- **当** span 的连续格子共享同一 link id
- **则** 其间不产生多余的开关序列

#### Scenario: 不支持的终端不发射
- **当** 终端不在 OSC 8 白名单内（例如 Apple Terminal.app）
- **则** 字节流不含任何 OSC 8 序列，渲染与无该特性的构建一致

### Requirement: 悬停链接在气泡中显示真实 URL
在启用了悬停移动上报的终端上，指针无按键停留于链接区域约 300 ms 后，TUI 应（SHALL）在指针附近显示浮层气泡，展示该链接的真实 URL。指针离开区域或用户按 Esc 时气泡应（SHALL）消失；气泡不得（SHALL NOT）改变布局或捕获输入。

#### Scenario: 停留显示真实 URL
- **当** 指针无按键悬停在链接区域约 300 ms
- **则** 指针附近出现气泡，显示该链接的真实 URL

#### Scenario: 移开或 Esc 隐藏气泡
- **当** 指针离开链接区域，或气泡可见时用户按 Esc
- **则** 气泡消失

#### Scenario: 不安全的终端不启用悬停移动
- **当** TUI 启动于 any-event 鼠标上报不安全的终端（老式或经典 Windows 控制台宿主）
- **则** 悬停移动上报保持关闭、不显示气泡，其余行为不变
