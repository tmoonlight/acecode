# 设计

## 发布范围

复用受保护 master 的集成与版本 PR。近期 worktree 按固定窗口与完成依据盘点；已经包含的提交及内容等价补丁不重复应用；源码和最终包分别验证。

## 本机测试进程结果

GTest 重复运行仅把最后一轮结果写入 XML，进程退出码反映所有轮次。运行器逐进程结合这两个信号：退出码 0 正常；退出码 1 且该进程 XML 记录断言失败时，继续现有失败与基线对照；其它非零退出必须阻断。超时使用的负数退出码保持在 JSON 中，避免同组成功进程通过 max 运算将其覆盖为 0。

解析失败、缺失 XML 与已有基线失败维持原有判断。生产 MCP 连接与配置读写代码保持本次输入基线；首次失败与压力重复中的启动超时如实保留，最终全量结果另行验证。
