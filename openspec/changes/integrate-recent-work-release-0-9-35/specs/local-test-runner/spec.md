## ADDED Requirements

### Requirement: 测试进程退出与 XML 一致性
本机测试运行器 MUST 校验每个子进程的退出状态，并在 XML 无法解释非零退出时阻断成功报告。

#### Scenario: 重复测试最后一轮成功
- **WHEN** GTest 重复执行的早期轮次失败、最后一轮 XML 全部通过，而进程退出码为 1
- **THEN** 汇总运行必须失败，并记录对应子进程及退出码

#### Scenario: 超时留下已有 XML
- **WHEN** 子进程超时并以负数退出码记录，即使留下已有 XML 且其失败已在基线中
- **THEN** 汇总运行必须失败，JSON 必须保留该负数退出码

#### Scenario: 已有断言失败仍可与基线对照
- **WHEN** 子进程以 1 退出且该进程 XML 的断言失败均为允许的已知基线失败
- **THEN** 继续按照现有基线对照规则判定，不把普通断言失败重复归类为未知进程故障

### Requirement: 异步回调测试依赖的析构顺序
通道测试 MUST 使回调引用的记录器存活到传输对象停机完成，包含测试断言提前返回的路径。

#### Scenario: 析构传输对象时仍有停机回调
- **WHEN** 测试退出作用域，传输对象在析构过程中发送最终状态或排空入站消息
- **THEN** 回调记录器必须仍然存活，且测试进程必须正常退出
