## 测试汇总修复

发布检查发现，GTest 重复执行时可能先失败后成功，XML 只保留最后一次，而进程仍以 1 退出；当前汇总器忽略这个差异。修复后，无法用该进程 XML 中的失败解释的非零退出必须阻断，包括超时和异常退出；已有基线失败的对照语义保持。负数退出码也必须在 JSON 中保留。
