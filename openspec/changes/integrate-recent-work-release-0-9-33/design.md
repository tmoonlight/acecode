## Context

45 个注册 worktree 的状态、最近提交、文件时间及当前 master 覆盖情况已盘点。两个近期脏 worktree 分别为 cranky-jemison-14c349 与 ecstatic-dirac-7e2088；它们的 HEAD 已在 master，未提交差异只有部分已被此前复制整合。近期 reflog 中 preview-mesh-sync 暂存快照主要由 329faf92 和蜂群提交覆盖，需逐项核对避免重复应用。

## Goals / Non-Goals

目标：完整整合有效改动，保留原有行为，修复发布阻断，并从唯一最终 master 提交生成完整发布。非目标：清理旧 worktree、重写历史、改变未涉及的功能、把尚未完成的 Claude 工作当成完成。

## Decisions

1. 对比 worktree HEAD、当前 master 与脏文件做三方合并；源文件哈希核对后才写当前工作区。已有 UTF-8 修复不重复提交，冲突处保留公共安全 JSON 序列化与所有独立回归用例。
2. `/tasks` 按现有独立命令模块模式拆出注册函数，保留原来的注册位置；不抬高 2060 行基线，不删除行为绕过检查。
3. 使用新的 0.9.33 标签，不覆盖失败的旧版本标签。受保护 master 通过既有 PR 流程交付，最终同一提交的测试通过后才创建标签并发布。
4. 六种更新 ZIP、双架构 macOS 签名公证 PKG 及完整 18 项下载产物均须存在并校验。更新 manifest 保留 Linux 能力版本目标，PKG 不混入自动更新项。
5. 发布完成后读取 Claude 的运行/任务记录核实终态；只有明确结束且无在途工作才执行用户授权的关机。

## Risks / Trade-offs

- 多处补丁已部分合入：三方合并及逐文件比较防止丢失较新行为。
- 本地构建目录的可执行文件仍被桌面占用：优先构建独立测试目标，构建发布可执行文件前核对进程任务状态，仅停止明确需要释放的实例。
- macOS 凭据或跨平台 CI 仍可能失败：保留标签/资产，修复具体原因，不把部分发布报告为完整。

## Migration Plan

无配置结构迁移。本轮未新增种子资源，仍需比较最近正式版到最终提交的 seed 内容和协调逻辑，并按实际差异执行升级检查。
