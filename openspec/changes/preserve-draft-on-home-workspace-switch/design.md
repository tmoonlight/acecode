## Design

区分当前首页草稿的存储键和新会话的工作区。工作区下拉第一次切换时，在首页导航引用中记录 `homeDraftWorkspaceHash`（含空字符串和专用草稿作用域）；后续切换沿用该键。ChatView 的恢复、上传回填、自动保存和提交后清理继续使用同一草稿键，创建会话仍使用当前选择的工作区。

左侧新建任务创建不带固定草稿来源的新引用，因此恢复各工作区原有草稿。此方式不会用当前输入覆盖另一工作区的既有草稿。导航身份和可传输记录需包含首页草稿来源，避免同一目标工作区的不同草稿引用被合并。会话引用不携带此首页字段。

回归使用实际 App、输入组件和草稿存储，通过 HTTP fixtures 隔离后端；必须验证修复前下拉切换会清空输入，修复后保留内容，并且不同工作区已有草稿仍可从左侧恢复。
