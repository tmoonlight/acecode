## Context

动机见 proposal.md。现有 ToolResult 已提供图片附件，但 OpenAI 工具结果丢弃附件，Anthropic 将其转为省略文本。内置工具共享注册器服务于 daemon 和 TUI；现有普通工具审批仍适用。Codex 开源部分负责 MCP 接入，实际 Windows 原生插件为专有发布物。

## Goals / Non-Goals

**Goals:** 在 Windows 本机交互桌面形成可取消的观察、操作、再观察闭环；开关是实际执行边界；兼容现有模型和聊天记录。

**Non-Goals:** 本次不实现 macOS/Linux 原生控制，不复制 Codex 专有运行时，不引入 JavaScript REPL 或绕过 Windows 完整性级别限制。

## Decisions

1. 使用 C++17 原生 sidecar `acecode-computer-use`，由 daemon/TUI 通过私有 stdin/stdout JSON Lines 通信。与内嵌 UIA 相比，阻塞第三方应用可以被超时或取消终止；执行器随安装包交付。
2. 后端采用 UI Automation、SendInput 与 Windows.Graphics.Capture；截图必须携带来源、原点和尺寸。WGC 不可用时仅允许明确标注的可见屏幕回退，并检查目标无遮挡，避免将别的窗口像素当作目标截图。
3. 工具组使用观察结果的 observation_id 绑定窗口进程、几何、元素索引和截图坐标。截图最长边最多 2560 像素，避免后续附件归一化再次缩放；返回原生尺寸、截图尺寸和缩放比例。动作坐标及控件 bounds 使用实际返回的截图像素，由后端转换为屏幕物理像素。每次写操作消耗观察；过期状态拒绝执行。密码控件值不进入树文本。
4. 一个会话持有执行器及桌面控制租约；Windows 命名互斥量阻止多个 ACECode 实例同时控制同一交互桌面。子代理也不能并发抢占。输入批次包含释放事件；操作有超时、取消探针。结束回合、关闭开关、进程退出均释放 worker。
5. 开关默认 false。配置更新同步刷新注册表并撤销运行时权限；工具执行前再次检查启用状态，不能依赖模型侧 schema 隐藏。保持现有权限模式审批，Plan 模式不允许变更桌面。
6. OpenAI 兼容请求将工具截图转成整批工具结果之后的用户图片消息，Anthropic 使用 tool_result 内 image block；图片仍保留为工具来源的规范记录。非视觉模型保留文字观察与明确图片不可读提示。
7. 相关瞬态界面属于同一个一次性观察，但每个界面保存独立 HWND/进程身份、归属关系、几何和截图标识。采用明确 owner 链、标准菜单所属窗口或 ComboBox 列表句柄验证关系；同进程/线程不足以构成归属证据。输入按指定截图或控件所属界面换算及命中检查，菜单状态变化使观察失效。
8. 多图来源随图片附件持久化，并在模型消息中紧邻图片标注真实 screenshot_id 和尺寸。关键操作信息置于工具预览开头；图片失效或省略不能使其他图片错配。
9. helper 在独立 UI 线程绘制不抢焦点、鼠标穿透的指针层，显示最后成功动作的位置、移动和点击反馈；UIA 控件操作也产生可见反馈。只记录本进程实际创建的 overlay HWND，避免其进入窗口列表、遮挡判断和观察关系。输入命中检查及屏幕回退抓取期间同步临时隐藏，release、取消或 helper 退出时清理，不替换全局系统光标。
10. WGC 显式关闭内嵌光标，再与屏幕回退共用指针合成器；不支持关闭内嵌光标的旧版本使用已验证无遮挡的回退。优先合成操控指针，否则读取系统光标；只有热点实际属于当前窗口或子控件才绘制。先按物理像素合成，再随整张截图缩放，同时返回截图像素的 cursor 元数据，处理热点、透明度、裁切和负屏幕原点，防止重复光标或坐标漂移。
11. 设置页沿用完整 SectionTools 的统一工具行结构，图标、文案、操作区和分隔线在同一个平面列表中对齐；验证完整页面，不能仅凭独立组件通过判断布局正确。
12. 电脑操控以“（实验性）”标注，行内配置展开两张同尺寸预览单选卡；默认带 ACE，另一款纯色。选择和运行时使用同一持久化 pointer_style；解析后的主题强调色通过既有配置 API 同步到 pointer_color，由 broker 注入可信 helper 请求，不允许模型覆盖。前端读取实际 --ace-accent，兼容内置、下载和自定义主题及系统明暗变化，避免在原生端复制主题色表。样式与颜色更新不改变启用状态、不销毁活动观察，后续操作/截图应用最新外观。

## Risks / Trade-offs

- UIA 应用响应慢或死锁 → 独立 worker 与请求截止时间，失败后重新观察。
- 系统窗口、UAC 安全桌面、受保护内容或高完整性应用不能操作 → 返回明确能力错误，不重试盲点。
- 用户移动窗口或多个会话竞争输入 → 观察时绑定身份和几何，操作前确认，租约拒绝并发。
- Windows 不同工具链可用的 WinRT 头不同 → 条件编译、明确回退来源和打包说明，验证当前 MSVC 构建的 WGC 路径。

## Migration Plan

旧配置缺省保持关闭；开启无需重启；关闭立即撤销。安装时附带匹配版本 helper，缺失时返回安装错误。回退版本时未知配置字段由既有配置兼容机制处理。
