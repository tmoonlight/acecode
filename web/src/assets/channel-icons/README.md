# Message-channel icons

These local SVGs are imported by `ChannelPlatformIcon.jsx`, so Vite embeds them in
the application bundle. The UI never fetches brand assets from a CDN.

- QQ, WeChat, Telegram, Discord and LINE: [Simple Icons 16.0.0](https://github.com/simple-icons/simple-icons/tree/16.0.0), CC0-1.0; see `simple-icons-LICENSE.md`.
- Feishu: [Semi Design 2.101.0](https://github.com/DouyinFE/semi-design/blob/v2.101.0/packages/semi-icons/src/svgs/feishu_logo.svg), MIT; see `semi-design-LICENSE`. Its monochrome artwork has a transparent background and is inverted in the dark theme for contrast.
- DingTalk: [Remix Icon 4.6.0](https://github.com/Remix-Design/RemixIcon/blob/v4.6.0/icons/Logos/dingding-fill.svg), Apache-2.0; see `remixicon-LICENSE`.

Exact download URLs, original hashes and fill-color adaptations are recorded in
`sources.json`. Brand marks identify the corresponding integrations.
