# 会话分享

在会话标题栏「属性」左侧点击分享图标，选择链接权限、可见内容和有效期，再生成链接。

| 链接权限 | 访客能力 |
| --- | --- |
| 只读 | 查看历史、图片和实时进展，没有聊天入口 |
| 可交互 | 在查看之外进行独立提问；使用分享者的模型和受限只读工具 |

「只看对话 / 含工具输出」独立于链接权限。默认可交互、只看对话、一天过期。复制邀请包含主人名、会话标题和链接；复制链接只复制 URL。存在有效分享的会话在侧栏显示雷达图标。侧栏快捷菜单中的「分享与连接」管理有效分享、提问记录和已保存对端。

## 连接与权限

链接格式为 `acecode://connect/<base64url>`，载荷是 UTF-8 JSON 加四字节大端 CRC32，不带 Base64 填充，最长 1024 字符。CRC32 只检测损坏；链接是访问凭据，编码不提供加密。第一版使用明文 HTTP/WebSocket，仅适用于可信局域网，不提供公网穿透或 TLS。

JSON 短键：`v` 版本、`n` 主人、`t` 会话标题、`a` 候选地址、`p` 端口、`c` 分享凭据、`e` Unix 秒过期时间。未知字段忽略，未知主版本拒绝。凭据由 16 位十六进制分享标识、点和 32 个 Base64URL 字符组成；随机 secret 为 192 位。

系统协议、剪贴板和输入框粘贴统一进入确认框，显示主人、标题和地址。确认之前不进行网络请求。取消粘贴识别后，原文回到输入框原光标位置。

Windows 安装器及绿色版启动时按当前用户注册协议，无需提权；已有的另一个有效安装不会被覆盖，卸载只移除自己的关联。第二实例用现有的 open-request 交接文件传递邀请。macOS 在应用信息中声明协议并接收 URL 事件；Linux 通过 `.desktop` 和 `xdg-mime` 注册，第二实例通过每用户 Unix socket 唤醒主窗口。

访问私有、链路本地、IPv6 唯一本地地址及单段电脑名时强制直连。候选地址依次尝试，每个地址连接最多三秒，电脑名优先、物理网卡其次、虚拟网卡最后。自动监听端口依次尝试 12400、daemon 相邻端口、系统分配端口；显式 `web.remote_port` 保持固定端口语义。

## 访客提问

提问在分享者机器上执行，复用侧边对话的流式循环。可用工具只有当前会话本来允许的只读文件、搜索和 LSP 工具。额外禁止 `.env*`、私钥、证书、`.npmrc`、`.netrc`、`.git-credentials` 等路径；搜索结果也经过过滤。访客不能转发消息给主会话、改文件、执行 shell、审批或中止主任务。

问题不写入主会话历史、不占用主会话忙碌状态。每个分享码同时最多一个提问，默认每天 30 次，按 UTC 日期重置，响应带下一次恢复时间。检查在调用模型之前进行；只读链接的提问不会消耗额度。

历史、实时输出和答案都经过脱敏。为避免密钥跨流式片段泄露，未完整的文本行及 PEM 块先缓冲，再脱敏发送。脱敏规则不能识别所有可能的秘密，分享者仍应选择适当的内容档位。

## 存储与撤销

- `<data_dir>/shares/shares.json` 保存分享记录、secret、权限、过期时间及日额度，采用 JSON 文件事务。
- `<data_dir>/shares/<share_id>.asks.jsonl` 保存已脱敏提问记录，每条分享最多 200 条。
- `<data_dir>/peers.json` 保存已确认的对端，所有工作区共用。前端列表只获得凭据末四位。

撤销先使凭据失效并关闭现有连接。只要存在有效分享，局域网转发可以独立于远程 Web 开关运行；远程 Web 关闭时，经转发进入的完整 daemon token 也无法访问管理接口。最后一条分享失效且远程 Web 未开时停止转发。

接收方网页只访问自己的 daemon。对方的网页、脚本、样式不被加载；可执行 `visual` 块显示源码，Markdown 外部图片不自动请求，允许的会话图片经本机鉴权接口读取。

## 剪贴板

Windows 使用剪贴板变化通知，后台或托盘状态下先显示通知，点击后再确认；macOS 只在窗口激活时检查。在读取前尊重禁止监视、禁止历史和平台隐私设置，只检查前 8 KiB；普通文本不落盘、不记录、不外发。同一邀请每个进程只提示一次；应用自己复制的邀请不会提示自己连接。

设置 → 常规的「识别剪贴板中的会话邀请」即时保存，默认开启。关闭后仍可主动打开协议链接或粘贴到输入框。macOS 的 URL 模式探测是否识别自定义协议仍需真机验证，验证状态见 OpenSpec 任务清单。

## AI 工具

`list_peers` 列出已保存对端，`read_peer_session` 读取有界回合摘要，`ask_peer_session` 向可交互对端提问。后两者只接受 `peer_id`，不能自行指定网络地址或分享码。工具在 TUI、daemon、headless 启动期固定注册；所有结果明确标记 `external_untrusted`，不应把返回文本当作操作指令。

若访客让自己的 AI 调用提问工具，访客自己的模型调用和分享者回答问题的模型调用分别消耗各自额度。

接口见 [daemon API](daemon-api.md)。实现边界为 `domain/share`、`host/session_share`、`host/peers` 和 Web 独立访客路由。
