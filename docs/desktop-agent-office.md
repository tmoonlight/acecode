# 桌面宠物与 Agent 虚拟办公室

Windows 与 macOS Desktop 可开启透明桌面宠物，默认关闭。设置 →「桌面宠物」提供「虚拟办公室」「大眼回形针」「rover」「鲸鱼娘」四种选择，选择与显示开关独立保存，切换即时生效并保持窗口位置、大小和置顶状态。关闭时选择宠物不会自动开启。

大眼回形针与 rover 使用经典原始精灵图（分别 43 与 29 个动作）；鲸鱼娘使用 vlln/whale-girl 的全部 15 套帧动画。它们的动作与交互复刻 Codex Mini 宠物（下节），支持现有拖动、缩放、跟随、置顶和关闭操作。它们**有意不理会系统的「减少动态效果」**（用户拍板）：远程桌面会话只要关了窗口动画，WebView2 就报告 `prefers-reduced-motion: reduce`，宠物会整只冻住；虚拟办公室仍按系统设置不走路。素材内嵌程序，运行时不访问外部资源。来源、固定提交、哈希与上游许可位于 `assets/desktop_pet/classic/` 和 `assets/desktop_pet/whale/`。

## 陪伴宠物的动作与交互

行为引擎在 `assets/desktop_pet/classic_pet.js`，对照 Codex 桌面版 Mini 宠物的实现（`avatar-overlay-native-page` 与精灵播放器：状态 idle / running / waiting / failed / review / waving，悬停 jumping，拖动 running-left / running-right）。每只宠物在 `PROFILES` 里把这套词汇映射到自己的原始动作，改动作只改这张表。

- **没有顶部工具条**：陪伴宠物不显示最近五个会话、跟随、置顶和关闭按钮；右键菜单提供「切换宠物」二级菜单（四种宠物，当前那只打勾，与设置页走同一条保存路径）、「回到右下角」「保持置顶」、缩放和「隐藏桌面宠物」。四种宠物（含虚拟办公室）的右键菜单相同。
- **会话卡片（复刻 Codex Mini）**：每个正在运行、等你处理、失败或完成后还没看过的主会话一张卡片，跨工作区，按最近发消息时间排序：加粗标题 + 一行内容，字体、字号、行高与 ACECode 对话正文完全一致（主页面每次推送快照都带上当前的 `--font-sans` 和 `--ace-font-size-13`，跟随设置里的小 / 中 / 大字号，默认 14px、行高 1.6）（运行中是最新输出或正在做的事，完成是回复开头，失败 / 等待各有提示），完成带绿色对勾，失败红色、等待橙色，运行中有转圈和 ■ 停止按钮。多张时收拢成一张、后面露出两层卡边；点一下展开成列表，点卡片打开那个会话（主窗口到前台并切过去，已完成的卡片随即消失，因为打开即标为已读）；悬停卡片左上角 × 移除（完成 / 失败的同时标为已读，运行中的只暂时隐藏到状态变化）；鼠标离开展开的列表 1.5 秒后收回。**没有会话动态时一张卡片都不显示**，窗口那片区域也不拦截点击；只在宠物出现时显示约 6 秒的招呼卡片，断线时显示「连接已中断」。数据来自 `/api/desktop-office` 的 `activities`（见 daemon-api），完成未读与侧栏未读点同源。
- **出场**：先打招呼（回形针 Greeting、rover 跑进来再打招呼、鲸鱼娘挥手），同时显示招呼卡片「你好，我是…」「双击我就能打开 ACECode」，点一下可提前收起。
- **静止时永不静止**：循环播放闲置动作，每 7–16 秒随机插入一个预置动作（回形针玩原子、绳子、东张西望等，rover 运动、做饭、看书等，鲸鱼娘玩耍、吃东西、挥手、开心），连续两次不重复。鲸鱼娘和 rover 带轻微呼吸起伏；原版动作里自循环超过 1.2 秒的停顿会被跳过（回形针原版闲置会盯着一处好几秒）。空闲 5 分钟后入睡（仍有睡眠动画，rover 没有睡眠动作），任何交互或状态变化都会唤醒。
- **心情跟随卡片**：有会话等你处理时提醒一次再循环等待动作；否则有会话在跑就做最新那个会话对应的工作动作（思考 / 撰写 / 调用工具 / 压缩 / 重试，同类阶段切换时等当前动作自然收尾）；新出现完成卡片时庆祝几遍、新出现失败卡片时做失败动作，然后回到闲置。宠物刚出现时已有的完成卡片不会再庆祝一次。
- **悬停**：鼠标移到宠物身上跳一下（Codex jumping，3 秒内不重复），悬停期间整个宠物框可点，避免跳动改变轮廓导致悬停闪烁。
- **单击**：做一个回应动作（回形针挥手、rover 被点、鲸鱼娘挥手）；双击的第二下不会重复回应。
- **双击**：陪伴宠物双击把 ACECode 主窗口叫到前台（Codex Mini 也是直接打开主窗口），具体会话从卡片打开。虚拟办公室双击选中的人物打开其会话，双击空地打开当前会话，没有会话时也把主窗口叫到前台。Windows 由宠物窗口短暂挂接前台线程输入队列后激活主窗口（点击落在 WebView2 浏览器进程的子窗口里，本进程不一定有前台权限），macOS 走与通知点击相同的 `mac_bring_window_foreground`。
- **趴边偷看（只有鲸鱼娘）**：拖到屏幕左 / 右边缘附近松手（窗口中心离边缘不超过窗口宽度的 1/4，约等于身体碰到屏幕边），窗口贴到那条边，鲸鱼娘换成从屏幕边探出半个头、双手扒着边偷看的样子（贴左边时镜像）：缓慢地探进探出，每 2–5 秒眨一次眼、偶尔连眨两下；悬停时探得更靠里并开心地眯眼，有会话等你处理时也会多探出来一点，新完成的会话让她开心眯眼、失败时抖一下；双击照常打开 ACECode，再拖起来就恢复全身。缩放和恢复默认大小时保持贴边，「回到右下角」取消吸附。画面是用 Codex 按鲸鱼娘原有帧的画风画的两帧（睁眼 / 闭眼），来源与处理见 `assets/desktop_pet/whale/README.md`。偷看原画比精灵帧大约 1.8 倍（眼睛高度、发箍到嘴的距离都量过），按常规帧缩放 ÷ 1.8 绘制，头和站着时一样大；曾经固定画成 170 像素高，头大了将近一倍。吸附判定与贴边位置是 `desktop_pet_layout` 里的纯函数（`desktop_pet_dock_side` / `dock_desktop_pet`），原生在拖动结束时判定并发 `{type:'pet-dock', side:'left'|'right'|''}`。
- **拖动**：原生拖动循环按窗口横向位移向页面发 `{type:'pet-drag', phase:'start'|'move'|'end', direction}`（`DesktopPetDragTracker` 累计 4 像素才报方向）。鲸鱼娘整个拖动过程都是被一只手拎起来的姿势（drag 帧）并以手为支点轻轻摆动；回形针朝拖动方向看；rover 先吃惊再朝拖动方向看，停住 0.45 秒转回正面。松开后继续原来的状态。松手时没有吸附，窗口又有一部分在屏幕外，就整窗收回工作区（`keep_desktop_pet_in_work_area`，所有宠物都适用）。吸附要窗口伸出屏幕约 1/4 宽，只是蹭到边上松手，正好会停在半出屏的位置，头顶的会话卡片会被屏幕边截掉。

虚拟办公室继续显示主/子 Agent 的完整协作场景。单会话有一个主角色 Maestro，多 agent 任务按真实子会话入座；无需启动额外模型，也没有演示任务循环。美术与拖动缩放来自原有 Claude 桌宠，旧的 `design-prototypes/agent-office` 事务所原型已移除。

## 操作

- 左下角齿轮菜单的“显示桌面宠物 / 隐藏桌面宠物”位于“设置”和“外观”之间。设置里的“桌面宠物”位于“个性化”和“使用情况”之间，提供同一个开启开关。
- 从 0.9.37 稳定版起，没有保存过选择的用户会收到一次开启邀请。关闭或选择“暂不开启”保持关闭；以后仍可从菜单或设置开启。预览复用嵌入的办公室 HTML，在独立沙箱 iframe 中播放演示，关闭弹框后释放；支持暂停和系统的“减少动态效果”，不访问真实会话或额外网络。
- 「更多宠物」宣传：已经答复过上面邀请的老用户，启动后弹一次「增加更多宠物，丰富您快乐工作的每一天」，只展示大眼回形针、rover、鲸鱼娘的图和名字，不加说明（用户要求）。点一只就切成它，宠物没开就同时开启；「知道了」关闭。`office.json` 的 `pets_promo_seen` 记录是否看过，由 `aceDesktop_claimPetsPromo` 原子认领。新用户认领开启邀请时，或者没看过邀请就在设置里开关宠物时，这个标记一并置位，不会连弹两个窗。弹窗在 `components/DesktopPetsPromo.jsx`，与开启邀请共用遮挡与引导让位规则。
- 顶部菜单在鼠标移入办公室时显示，移出后保留 1 秒再隐藏；重新移入会取消隐藏，键盘操作时保持可见。隐藏菜单的透明区域可穿透点击。
- 菜单下方显示当前会话标题，切换或改名后同步更新；长标题单行省略，悬停可查看全文。断线或尚无选中会话时保留对应状态提示。
- 菜单右侧 pin 控制办公室是否始终置顶：默认置顶，取消后可被其他普通窗口覆盖，拖动、缩放和停靠均保持当前选择；重新启动桌宠恢复默认置顶。叉号只关闭办公室并同步菜单/设置的关闭状态，不退出 ACECode，也不停止 agent 任务；可在同一次运行中重新开启。
- 顶部显示跨工作区最近发过消息的五个主会话。顺序只看用户最后发送消息的时间，打开、切换和 agent 输出不会把会话顶到最前面。
- “跟随”默认开启，办公室随主窗口当前会话切换。点击门牌会关闭跟随并固定办公室；再次打开跟随后恢复跟随。查看最近五个之外的当前会话不改变门牌排序。
- 切换会话等待新快照时保留当前办公室的布局、角色和标题，新快照就绪后一起切换，避免中途闪现默认布局。快速连续切换只应用最后一次选择；真实空会话或会话不存在时仍显示空态。
- 主 agent 成功完成后留在座位显示 `zzz`，下一轮自动醒来；成功完成的子 agent 立即离座，重新工作时以同样的外观返回。
- 忙碌的 agent 头顶常驻状态气泡：「图标 动作 · 细节」。正在输出时显示「撰写回复」和最新的几个字（打字动画 + 光标），推理时显示思考点和推理尾巴，调用工具时显示动作（读取、运行命令、修改代码…）和调用预览（路径、命令）。默认「用于编程」模式下服务端不发正文进度，桌宠由 token 事件推断。气泡互相避让：先左右错开，再抬高并用引线连回头顶，放不下时只留动作。
- 子 agent 出现时门先打开，人从门槛淡入走进来，先到派活的人桌前领「任务」信封再回工位，坐下后跳一跳、冒星星、说「报到！」；完成后走到派活的人桌前递「回报」信封（派活的人显示「收到…的结果」），说「再见」后快步出门、在门槛淡出；失败或停止的成员直接道别出门。网状协作中 agent 间消息以带「消息 / 新任务 / 回报」标签的信封在工位间飞过。系统开启「减少动态效果」时不走路，交接信封、「报到！」和原地「再见」仍然显示。
- 等待授权、等待回答、重试、压缩、失败和取消有各自状态。超过七个子角色时点击 `+N` 查看成员并打开对应会话；列表随状态更新，Escape 收起。选中房间人物后双击可打开其会话；双击空地打开当前会话，没有会话时也会把 ACECode 主窗口叫到前台。
- 文件堆随当前上下文占用增长，压缩后依据实际新统计变薄。工具符号与聊天工具行共用 SVG 来源。
- 拖动房间空地移动窗口；滚轮、右下角把手和右键菜单可缩放。窗口不抢主界面焦点，透明角落可穿透点击；尺寸按原实现保存。

## 构建与数据流

由当前工作区的 `scripts/dev_desktop.bat` 启动开发版。先构建 `web/`，再配置/构建 CMake Desktop，使内嵌主界面与桌宠资源保持一致。`ACECODE_DESKTOP_PET=0` 可对本次进程禁用桌宠；Linux 当前没有原生桌宠窗口实现。

macOS 版（`src/apps/desktop/desktop_pet_mac.mm`，ARC 编译）用非激活 NSPanel + WKWebView 承载同一份页面：文档开始前注入 `window.chrome.webview` 垫片，页面代码不分平台；透明区域的点击穿透靠定时检测鼠标是否落在房间、控制条或页面上报的浮层里，再切换 `ignoresMouseEvents`；拖动与把手缩放由定时器跟随鼠标。默认 1.25 倍（约 430×315 点），设置存 `~/Library/Application Support/ACECode/desktop-pet/settings.json`。

macOS 在原生左键按下时保留鼠标接收和原始窗口位置，防止异步拖动消息到达前被切换成点击穿透。注入桥为画布及缩放把手捕获 pointer，画布以页面坐标判断 4 点拖动阈值；松开、取消、页面重载和关闭都清理交互状态。把手的方向光标由 AppKit 设置，位置随窗口比例变化、命中大小保持 16 点；未置顶且被其它窗口覆盖时不改动其它窗口的光标。

数据链为：会话元数据/事件分发器 → `GET /api/desktop-office` → App 级办公室控制器 → 原生 WebView 桥 → 像素场景。控制器复用现有引用计数 WS 订阅，事件触发刷新并以 3 秒轮询兜底；正在加载旧记录时短间隔继续读取。快速切换以请求代次和取消信号隔离迟到响应；隐藏或页面卸载释放订阅和计时器，重开/重载从原生缓存恢复当前选择与跟随状态。

Windows/macOS 共用 `desktop_office_service.hpp` 管理偏好、桥和可重建窗口。桥在主页面导航前注册，避免 WKWebView 首次加载时漏掉会话联动。`enabled`、`welcome_seen` 和 `pet_kind` 原子保存到桌宠目录的 `office.json`，与现有 `settings.json` 缩放设置分开；旧配置默认 `pet_kind=office`，无效值也回退虚拟办公室；Windows 目录为 `%LOCALAPPDATA%/ACECode/desktop-pet`，macOS 为 `~/Library/Application Support/ACECode/desktop-pet`。

页面把成员列表、提示和状态气泡的矩形（节流后）上报给原生窗口：Windows 的窗口区域同时裁剪绘制，冒出墙顶的气泡必须并入区域才不会被切掉；macOS 用同一份矩形判断点击穿透。

断线时明确显示正在重连，恢复后重取真实快照。错误和取消不会被当作成功睡眠。只同步小型展示字段，不通过动画触发或控制 agent 任务。

视觉规则见 [桌宠设计](../assets/desktop_pet/DESIGN.md)，协议见 [daemon API](daemon-api.md)。验收命令及本次实测范围见 [交付记录](../openspec/changes/integrate-desktop-agent-office/verification.md)。

## macOS 接续验证

本次在 Windows 完成原生窗口与 Web 交互验证；macOS 的源码已同步，尚未在 Mac 编译或运行。Mac 接续时先构建 `web/` 再配置/构建 Desktop。确认默认不出现办公室；菜单开启后选择、切换真实会话，检查标题、主/子角色和工作气泡；叉号关闭后从设置重新开启，检查继续跟随；退出重启检查开关持久化。版本达到 0.9.37 后首次提示应出现一次，关闭/拒绝后不再自动提示，预览关闭后也不保留 iframe。测试一次性提示时使用独立测试用户配置，勿删除日常偏好。

2026-10-09 鼠标修复的可移植 C++、Chromium 和 Windows WebKit 验证见 [修复验证记录](../openspec/changes/fix-macos-desktop-pet-pointer/verification.md)。Mac 仍需确认：ACECode 未激活时把手显示对角缩放光标；快速拖过透明角落和窗口外再松开、连续再次拖动正常；把手双击重置、普通角色点击及菜单按钮正常；取消置顶后被其它应用覆盖时不干扰光标；关闭/重开及跨显示器后交互正常。Windows 上的 WebKit 测试不等于 macOS NSPanel/WKWebView 实机验收。

## 四种宠物的验证

`node web/scripts/test-classic-desktop-pets.mjs` 覆盖三种新增宠物的离线解码、出场招呼、鲸鱼娘全部 15 套动作、工作 / 等待 / 失败 / 成功状态、闲置动画最长静止时长、随机预置动作、悬停跳动、单击回应、双击打开会话或仅激活主窗口、拖动左右方向、入睡与唤醒、开启减少动态效果时照样动、会话卡片（无会话不占位、收拢 / 展开 / 打开 / 停止 / 移除）、没有工具条、右键菜单和多尺寸布局；`ACE_OFFICE_HOST=mac` 用 macOS 桥垫片跑同一套。`test-desktop-office.mjs` 额外覆盖办公室空地双击。`node web/scripts/test-virtual-office-preferences.mjs` 覆盖四种选择与原有开关、邀请、订阅释放流程。Windows 上的 macOS 桥测试不等于 Mac 原生窗口实机验收。
