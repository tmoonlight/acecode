# 界面图标规范

ACECode 的操作、导航和状态图标使用同一套原创矢量图形。风格参考已检查的 Claude 图标：细线、圆端点、柔和折角和充足留白。图形定义不依赖 Claude 字体、安装目录或提取路径。

## 绘制和颜色

- 坐标统一为 `viewBox="0 0 20 20"`。多数可见轮廓位于 2.5–17.5 之间；圆形、斜线及细小符号按视觉面积适当调整。
- 圆角容器通常使用 1.5–2 单位圆角；路径拐弯使用 Q/C 曲线，端点及连接均为 `round`。
- 图标源的 paint 只能为 `currentColor` 或 `none`。不要加入 hex、RGB、命名颜色、渐变、嵌入位图或黑白遮罩。选中面板的实心区域和小圆点可以填充 `currentColor`。
- 状态红/绿/黄、强调、悬停和禁用颜色属于控件样式，使用已有主题变量。不得通过图标源颜色或 invert 滤镜表达状态。
- 同义名称共享图形；保留左/右/底面板和展开填充的语义区别、水平与竖向三点、图钉朝向、文件夹展开状态以及蜂群七单元。

## 尺寸与线宽

| 显示尺寸 | 常规线宽 | 20 坐标系线宽 |
| --- | --- | --- |
| 12 px | 0.8 px | 1.333333 |
| 16 px | 1.0 px | 1.25 |
| 20 px | 1.2 px | 1.2 |
| 24 px | 1.4 px | 1.166667 |
| 28 px | 1.6 px | 1.142857 |
| 32 px | 1.8 px | 1.125 |

共享组件使用 `0.05 × size + 0.2` 计算 CSS 像素线宽，再换算成矢量坐标；14/18 等中间尺寸按同一公式插值。`strong` 使用常规值的 1.25 倍（16 px 为 1.25，20 px 为 1.5）。避免通过父级 CSS 额外覆盖子 SVG 的 stroke-width。尺寸指图标占位，不是按钮的点击区域；修改图形不要缩小按钮。

左侧菜单与设置导航的功能图标统一使用 18 px：包括主要入口、扩展子项、展开箭头、工作区与会话操作、底部设置/反馈及其快捷菜单，以及设置窗口的菜单项目和搜索图标。按钮点击区域保持原样，常规线宽为 1.1 px。

会话标题、工作区与会话操作共用顶部一行；竖三点菜单位于控制台按钮左侧，侧边聊天和查找在菜单中保留原图标。功能组与 Windows 窗口控制组相隔 40 px。共享右键菜单分隔线是独立的 1 px 直线，不使用按钮上边框。

右侧列表面板与预览详情栏的列表开关共用 `ListPanel` 图形：三条左对齐、长度不同的横线，显示尺寸统一为 16 px。列表展开时按钮使用主题强调色和浅色背景表示激活；收起后的恢复入口使用普通状态。图标源仍仅使用 `currentColor`。

顶部标题栏保留 16 px 导航图标及 24 px 按钮占位，最小高度为 41 px；在原有 30 px 行的基础上，上方增加 5 px、下方增加 6 px。工作目录名优先获得空间，会话标题先省略，极长目录名允许换行撑高标题栏；按钮仍保持距顶部 8 px 的位置。macOS 原生三灯继续由 AppKit 定位，普通窗口保留左侧 80 px 避让，全屏时按既有逻辑取消避让。

独立导出的 SVG 是 20 px 常规原型。React 通过共享组件按尺寸计算线宽；HTML/CSS 使用独立原型作 mask 时按常规 SVG 比例缩放，不会获得组件的尺寸插值。

## 单一图形来源

- `web/src/lib/icons/controls.js`：基础操作、导航、面板和原来散落在组件中的功能图形。
- `web/src/lib/icons/system.js`：设置、状态、能力及工具语义图形。
- `web/src/lib/interfaceIcons.js`：统一注册、线宽计算和 SVG 序列化。
- `web/src/components/Icon.jsx`：现有别名与实际 React 渲染入口。新功能图标使用 `VsIcon`；不要再在业务组件里另画 SVG、叠字符或引用固定色图片。
- `web/public/vs-icons/*.svg`：由上述来源确定性生成，保留旧文件名兼容 markdown 和 CSS mask 消费者。

在仓库根目录运行：

```sh
node scripts/regenerate_web_icons.mjs
node scripts/regenerate_web_icons.mjs --check
node scripts/preview_web_icons.mjs --output=icon-gallery.html
```

最后一个命令创建独立、可搜索、可切换明暗/继承颜色的全量图标总览；输出路径可以指定到仓库外。总览包含放大轮廓、16/20/24 px 样本与逐枚 SVG 下载。不要手改生成 SVG；先修改 canonical 定义再重新导出。

## 范围

当前共有 122 个注册名称。MCP 服务器统一使用插头；专家入口使用人头轮廓加齿轮，均为空心描线；模型与推理仍使用 Brain。分享操作复用 Upload，已分享会话的状态标记使用 Radar。`interfaceIcons.test.js` 核对注册与公开文件一一对应、无固定色、线宽、真实组件渲染、ARIA、面板状态及文件类型独立渲染。

保留原样的内容：ACECode/供应商品牌 Logo、原生应用/托盘资源、Seti 字体与文件类型映射、PPTX 文件类型图标、统计图和动态百分比仪表。操作用 Document/Folder/OpenFile 属于功能图标，仍使用本规范。

本规范替代早期 IconPark 固定颜色/线宽以及侧栏、发送和窗口功能图标的旧例外。
