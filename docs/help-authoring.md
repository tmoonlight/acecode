# 帮助文档维护

[help/](help/) 是独立的静态文档包。直接打开 help/index.html 即可阅读，也可以将整个目录部署到静态网站。运行时不需要 Node.js、Python、npm、构建工具或 ACECode 后台服务。

## 内容范围

按用户 2026-09-05 提供的修订目录完成 7 个栏目、50 篇文章。所有二级文章都可阅读，指定的三级目录对应文章内二级标题，同时显示在左侧的文章展开项中。

| 栏目 | 文章数 | 内容 |
| --- | --- | --- |
| 开始使用 | 4 | 认识、安装、快速开始、更新与卸载 |
| 使用 ACECode | 8 | 桌面、TUI、CLI、Web、上下文、工作区、Git、用量 |
| 模型与服务商 | 6 | 概念、ACEModel、其他服务商、预设、能力、模型池 |
| 配置与扩展 | 12 | 配置、权限、代理、外观、规则、记忆、工具、技能、MCP、LSP、Hooks、连接器 |
| 进阶使用 | 6 | 专家、蜂群、定时任务、浏览器、消息渠道、实战 |
| 帮助与排错 | 8 | 常见问题、五类排错、反馈、速查 |
| 开发者 | 6 | 构建、架构、后台、API、扩展、贡献 |

## 内容源与生成

维护文件放在 [help-source/](help-source/)，不随最终 HTML 包分发：

- [tree.json](help-source/tree.json)：用户目录的单一来源，保存栏目、文章标题与指定小节。
- group1.py 至 group7.py：七个栏目的正文；部分较长栏目拆为辅助模块。开始使用正文保存在 getting-started.json。
- [common.py](help-source/common.py)：段落、表格、代码块和图片占位的生成辅助函数。
- [shell.html](help-source/shell.html)：共同的页头、导航、目录、搜索和页脚。
- [build_help.py](help-source/build_help.py)：生成 50 个完整 HTML、全文搜索索引、逐篇依据与配图计划。
- [sources.json](help-source/sources.json)：每篇文章所核对的项目源文件。
- [captures.json](help-source/captures.json)：Computer Use 原始截图的路径、应用、版本、采集时间和尺寸。
- [screenshot-map.json](help-source/screenshot-map.json)：稳定配图编号与本地原图的对应关系、图注和待补辅助画面。
- [pending-captures.json](help-source/pending-captures.json)：未取得画面的原因。
- [screenshot_assets.py](help-source/screenshot_assets.py)：验证并接入截图；原图以 SHA-256 校验，禁止引用截图目录以外的文件。
- [images.json](help-source/images.json) 与 [image-plan.md](help-source/image-plan.md)：每处配图的状态、标题、说明、原图依据和待补项目。

在仓库根目录执行：

~~~text
python docs/help-source/build_help.py
~~~

Python 仅供维护者生成文档。读者直接打开 HTML，不需要 Python。生成器检查文章完整性、明确的小节名称与顺序、源文件存在性、正文基本长度和图片编号唯一性。

修改正文后重新生成，不单独改某个输出 HTML，以免下一次生成覆盖。导航、页内目录、上一篇/下一篇以及搜索条目都会同步更新。全文及小节搜索当前共 207 条；description 是结果摘要，text 是检索正文。站内文章、锚点与资源都使用相对路径。

正文、栏目导航和页内目录保存在每个 HTML 中，关闭 JavaScript 后仍可阅读；运行时不请求 JSON、模板或内容接口。

## 样式与交互

样式位于 assets/styles.css。主色、背景与字体栈来自 web/src/styles/globals.css；文档使用直角容器和按钮。字号、行高、字重与文字灰阶按 [WorkBuddy 概述页](https://www.workbuddy.cn/docs/workbuddy/Overview) 的实际浏览器样式调整，测量日期为 2026-09-05。

| 元素 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 正文段落 | 16px / 28px | 400 |
| 正文列表 | 16px / 24px | 400 |
| 一级标题 | 32px / 40px；小于 768px 时为 28px / 40px | 600 |
| 二级标题 | 24px / 32px | 600 |
| 三级标题 | 20px / 28px | 600 |
| 左侧栏目 / 导航项 | 14px / 24px | 700 / 500 |
| 左侧三级目录 | 14px / 24px | 400 |
| 右侧目录标题 / 链接 | 14px / 32px | 600 / 400 |
| 表头 / 表格正文 | 14px / 24px | 600 / 400 |
| 提示正文 | 15px / 25.5px | 400 |
| 代码块 | 14px / 23.8px | 400 |

浅色文字依次使用 #3c3c43、#67676c、#929295；深色文字依次使用 #dfdfd6、#98989f、#6a6a71。第三级灰阶用于辅助标识。ACECode 蓝色保持浅色 #2563eb、深色 #3b82f6。手机端保留正文和导航字号，不整体缩小文字。

assets/theme.js 负责首屏主题和渐进增强标记；assets/docs.js 负责搜索、复制、导航与章节高亮。不使用网络字体、CDN、fetch、前端框架或服务端接口。代码块标题可换行，复制按钮保留单行。

## Windows 实拍与待补画面

55 处配图沿用 GS、UI、MD、CF、AD、TS、DV 编号。目前 40 处已接入 43 张本地 JPEG 原图，其中 8 个图组还缺辅助画面；15 处保留带标题和说明的占位。所有内容原图都由 Computer Use 操作 Windows 应用后采集，没有生成、重绘或拼接产品状态。导航和按钮的内联 SVG 仍为功能图标。

桌面截图来自实际运行的 ACECode v0.9.11。安装向导来自本机已有的 v0.9.6 安装包，图注明确版本，查看后取消，未执行安装。示例工作区 hello-acecode 实际完成欢迎消息修复及 3 项测试；代码执行结果、网络重试、排队消息、侧边聊天和循环失败记录均为实际画面。

凭据为空的新增模型表单用于展示填写位置；含 Token 的远程连接地址在采集前移出画面。模型、专家、专家团和循环的示例表单在截图后取消，没有提交反馈或向消息渠道发送内容。画面中的模型能力、端口和累计用量只表示截图时的状态，不写成产品固定值。

待补清单见 [配图计划](help-source/image-plan.md)。macOS 按要求暂不拍摄。TUI 经开始菜单入口及当前构建程序启动均未返回可操作窗口；后续 Computer Use 连续出现 GetCursorPos 访问失败，暂停了剩余界面操作。没有取得的认证、故障、子任务和共享状态继续保留占位。架构图属于示意图，也保留占位。

补图时先取得真实画面，保存到 help/assets/screenshots，向 captures.json 添加对应采集记录，再修改 screenshot-map.json 并移除相应 pending-captures.json 项。图注只描述实际画面；一组图尚缺其他状态时保留 pending_details。运行生成器即可同步正文、搜索与配图清单，无需修改原始正文中的占位编号。每张原图都有替代文本、固有尺寸和查看原图链接，离线及禁用 JavaScript 时同样可用。

## 内容核对边界

内容以当前项目源代码与实际界面标签为准，逐篇对应关系记录在 sources.json。旧手册存在过时的菜单、端口和开发流程描述，不能无条件复制。

本次已明确区分：

- 桌面本地路径引用、剪贴板图片附件与浏览器上传。
- 排队、插话、中断，以及主任务和子任务的确认来源。
- 桌面消息分叉、TUI 检查点回退与 Git 文件恢复。
- 模型预设名称、Model ID、探测缓存与重新探测。
- MCP 配置保存、重新读取编辑区、重连服务及实际工具加载。
- 专家对话式创建与高级模式、定时任务的权限与已错过记录。
- 独立 daemon、桌面托管后台和 Windows 服务的数据及生命周期。
- 默认后台端口 12399 与当前 Vite 开发代理目标 28080。
- HTTP 202 入队、WebSocket completed/error/aborted 终态，以及 client_message_id 不提供执行去重。

下载链接使用官方发布列表，不固定某个版本为最新版。外部链接只在读者主动打开时访问；文档阅读、搜索与页面控制不依赖外网。本次使用实际应用补拍配图，没有修改应用源码或发布网站。

## 打包与验证

将 help 下 50 个 HTML 文件、assets 中 4 个 CSS/JavaScript 文件以及 assets/screenshots 中 43 张已核对的 JPEG 原图打包到 ZIP 的 acecode-help 目录，共 97 个文件。打包白名单从 tree.json 和 captures.json 生成，后续补图时同步更新计数。不要加入内容源、维护文档、文档预览截图、测试脚本、Python 缓存或本机运行数据。

验证要求：

1. 7 个栏目、50 篇文章及全部指定三级目录的名称和顺序正确。
2. 所有本地资源、相对链接、锚点、翻页与搜索结果指向有效内容。
3. 55 处配图编号唯一；原图文件、SHA-256、替代文本与固有尺寸匹配，剩余占位有明确原因，无远程资源请求。
4. file 协议且离线时，在 1440、1024、768、375px 逐页检查阅读与页面溢出。
5. 检查明暗主题字号灰阶、三级目录键盘操作、全文搜索、页内定位与手机抽屉。
6. 禁用 JavaScript 后逐页检查正文与导航；剪贴板拒绝时显示真实的手动复制反馈。
7. 原图在各视口均成功加载、按比例显示，点击查看原图后可返回文章；禁用 JavaScript 也能加载图片。
8. 解压 ZIP 后检查全部文件字节与源码输出一致，并从解压目录再次打开与搜索。

浏览器检查使用独立离线 Chromium，不依赖 ACECode 后台。文档预览截图与验证报告保存在本次任务输出目录，不混入 HTML 包；实际产品截图随包分发。应用源码未改动，因此文档验证不声称完成了应用构建或尚未拍摄功能的运行测试。
