认识 ACECode

ACECode 是面向桌面与终端的 AI 编程智能体。围绕一个项目或任务，把理解代码、实施修改和验证结果串起来。

ACECode 能做什么

你可以直接描述目标，引用相关文件，让 ACECode 查找入口、阅读实现、修改代码并运行命令。回复区会显示回答、工具过程和需要你处理的操作确认。它使用你配置的模型与服务商，需要先保存一个可用模型。

你要完成的事如何开始
了解项目说明架构、主要入口、依赖和启动方式。
修复问题提供报错和复现步骤，要求先定位原因，再做最小修复。
实现功能描述预期行为、允许修改的范围与验收方法。
检查结果查看文件差异、测试输出和未完成事项，必要时继续补充指令。

任务记录可以恢复、搜索、置顶与归档。长对话支持压缩上下文；更专门的工作可使用技能、MCP、专家和子代理。权限模式决定哪些操作需要确认，模型能力、系统依赖和扩展连接状态决定实际可用范围。

桌面端、终端与 Web 如何取舍

入口适合的工作方式从哪里开始
桌面端在同一个窗口管理工作区、任务、文件预览和面板。桌面端指南
TUI在本地终端或 SSH 会话中以键盘完成交互。进入项目目录，运行 acecode。
CLI脚本或流水线中提交一次任务，获取文本或 JSON 结果。acecode -p --help
Web通过浏览器连接运行 ACECode 的计算机。启动 acecode daemon，打开输出的地址。

Web 中的工作区路径指向运行后台服务的计算机。桌面端具有原生文件选择和浏览器集成，直接 Web 不具备所有桌面专属功能。使用 SSH 时可以选择 TUI，也可以在远端运行后台服务后配置远程 Web 访问。

第一次使用，按安装、快速开始的顺序完成一个小修改，再按需要阅读后续栏目。
