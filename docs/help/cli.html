CLI

使用非交互的 print 模式执行一次任务，把结果交给脚本或流水线，同时保留可继续的会话。

本页内容
  • 执行一次任务
  • 选择输出格式与限制
  • 继续会话与启用扩展

执行一次任务

acecode -p 不打开 TUI。它读取命令参数或标准输入，执行一个智能体回合，将最终回复写入标准输出后退出。它仍可能调用工具；运行目录、模型和权限同样需要事先确定。

终端
acecode -p --permission-mode plan "阅读当前项目，说明入口和测试命令，不修改文件。"

也可以把已有文本通过管道传入；同时提供标准输入和提示词时，两者会合并。下面的命令请求审查当前差异：

终端
git diff | acecode -p --permission-mode plan "审查这些变更，指出可复现的问题。"
无交互环境中的权限

需要确认的操作不会像桌面端那样等待你点击按钮。分析任务可使用 plan；允许自动文件编辑但不放开命令时，使用 accept-edits。具体权限边界见权限模式。

选择输出格式与限制

参数作用
--output-format text默认，输出最终文本回复。
--output-format json输出单个结果对象，包含 session_id、is_error 和 result。
--output-format stream-json逐行输出已完成的文本、工具、错误等记录，不是逐 token 文本流。
--thinking在 stream-json 中包含完成的推理记录。
--model NAME选择已保存的模型预设名称。
--max-turns 10限制智能体循环次数；这不是 token 预算。
终端
acecode -p --output-format json --max-turns 10 "说明项目的目录结构。"

脚本应同时检查退出码和结果中的错误字段。退出码：0 成功，1 回合失败，64 参数错误，130 被中断。不要把标准输出中出现部分文本当作整项任务成功。

继续会话与启用扩展

终端
acecode -p --session-id docs-review "阅读 README 并列出缺失信息。"
acecode -p --resume docs-review "只为刚才列出的缺失信息提出补充建议。"

print 模式的 --resume 必须带 ID；继续当前目录最近会话使用 -c 或 --continue。自定义新会话 ID 最多 64 个字符，只包含字母、数字、短横线和下划线。

终端 · 只列出可用能力，不执行模型任务
acecode -p --list-tools --list-skills --list-mcp

print 模式默认启用可用的内置工具，技能和 MCP 需用 --enable-skills、--enable-mcp 点名开启；内置工具可用 --disable-tools 点名禁用。名称以列出结果为准，多个名称用逗号分隔。查看完整参数使用 acecode -p --help。
