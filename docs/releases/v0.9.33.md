# ACECode 0.9.33

- 新增网状蜂群协作：子代理可继续分工并互相传递消息，后台任务可打开对应子会话；子会话与主会话一同保存和删除。
- 新对话也可查看和选择思考深度，后台补齐模型声明；选择会带入新建会话。
- 修复蜂群通知穿插时重复显示「已处理」总耗时，保留各条通知和完整活动详情。
- 改善中文 Markdown 的粗体、斜体及中英文混排显示，保留原始消息文本。
- 修复 Windows 中文路径及系统错误导致升级接口返回异常的问题；升级失败信息可正常显示，诊断说明不再重复追加。
- 统一 TUI、桌面、网页与无界面运行的全局／工作区记忆，支持查看、编辑和可选的空闲摘要；长会话压缩保留最近摘要和用户关键指令。
- 加快长会话打开和侧栏刷新，修复重复工具调用 ID 导致的历史丢失、结果串用和旧输出覆盖，改善侧边对话及文件附件体验。

提供 Windows、macOS、Linux 和 UOS / Deepin 的完整平台下载包。安装新版后请重启 ACECode；macOS 同时提供 Intel 与 Apple Silicon 安装器及自动更新包。
