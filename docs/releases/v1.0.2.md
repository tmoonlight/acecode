# ACECode v1.0.2

- 详情页新增 Ctrl+滚轮字号缩放（50%–200%）与 Ctrl+F11 全屏演示；退出时恢复原有面板布局，保留编辑草稿、选区和光标。
- 自动压缩触发线最低为 40,000 tokens。低于该规模的请求被网关以“上下文过大”拒收时，保留完整上下文与工具，持续指数退避重试，并允许随时停止。
- 修复异常模型回复重试后仍可能执行工具的问题：连续返回损坏工具模板时明确停止，避免跑题修改文件。
- 修复模型只返回省略号、分隔线时被误判为任务完成的问题，自动重试后仍无有效回复会明确报错。
- 改善请求等待提示与响应诊断，保留已有的限流识别和压缩取消保护。
- 修复 macOS 桌面宠物缩放光标与快速拖动问题，完善透明区域穿透、松开与取消处理。
- 更新 Desktop/Web、TUI 内置帮助 skill 和 49 篇 HTML 帮助手册，补齐近期功能、操作与兼容说明。

升级后请完整重启 ACECode。Agent Browser 集成于 Desktop，无需独立浏览器宿主或扩展。

## 反馈处理说明

- 无标记的英文跑题：反馈正文已经包含无关英文内容，现有证据不能证明只是思考标签显示错误。客户端可以隔离标准推理字段并拦截明确损坏的工具模板，但不能可靠判断任意自然语言是否跑题；上游模型或网关仍需排查。出现同类情况可停止当前回合，换用可正常响应的模型后重试。
- 0.9.25 升级超时：新版已有 120 秒程序版本探测等待，旧版本的 5 秒升级器无法通过自身获取这一修复。若下载校验完成后仍报 `executable version probe timed out`，请关闭 ACECode，手动安装新版或将官方便携包解压到新目录启动；保留现有 `~/.acecode` 用户数据目录。安装完成后再使用新版自更新。
