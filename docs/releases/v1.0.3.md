# ACECode v1.0.3

- 修复模型服务报错后切换会话、刷新或重启导致红框提示丢失的问题。HTTP 451 额度用尽等错误现在会保存在会话记录中，保留原始详情；这些记录不会发送给模型或参与上下文压缩。同一次错误重放不会重复显示，不同回合的相同错误分别保留。
- ACEModel 默认采用 Responses 协议，模型设置中仍可切换为 Chat Completions。旧配置仅在未明确指定协议时采用新默认值，保留已有选择；安装器、模型目录和连接检测同步使用有效协议。
- 统一生成过程中的输入框主按钮：空草稿显示实心方块停止图标，有文字或附件时显示排队图标，回车或点击即可排队。按钮始终保持主题色背景，并保留停止在途、暂停队列和键盘操作反馈。

升级后请完整重启 ACECode；远端使用场景也需更新运行会话的服务器。旧版本未保存的错误提示无法补回。Agent Browser 集成于 Desktop，无需独立浏览器宿主或扩展。
