# ACECode v1.0.0

- HTML / HTM 文件预览新增浏览器按钮，可直接在 ACECode 内置浏览器中打开本地页面；支持中文、空格等路径，保留未保存修改的保存／放弃／取消提示。
- 设置新增可搜索的快捷键页面，支持新建会话、切换历史、展开面板、聚焦输入、调整思考深度等常用操作。
- 消息通道使用本地平台图标，移除图标圆角背景，稳定卡片布局并调整管理与连接按钮顺序。
- 优化长会话上下文与提示词缓存：保持已发送前缀稳定，持久保存上下文快照与更新，改进压缩后的任务清单和会话恢复。
- 子代理未指定模型时继承父会话当前模型；兼容模型服务的缓存字段拒绝与压缩重试。
- 更新入口移至左侧栏底部，保留更新进度与重启提示。
- 虚拟办公室支持独立偏好与欢迎预览，修复欢迎页面和新手引导同时出现时的启动卡死。

升级安装完成后请重启 ACECode。Agent Browser 集成在 Desktop 中，无需独立浏览器宿主或扩展。
