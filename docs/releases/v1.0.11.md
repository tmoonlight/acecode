# ACECode v1.0.11

- 新增语音识别输入，可选择麦克风、配置识别服务与快捷键，并在录音过程中暂停、取消或提交；修复麦克风右键菜单及 Linux 原生权限接口兼容性。
- 改进归档会话浏览，超过 100 条时滚动分批显示，保留搜索、筛选、批量操作与撤销入口；优化会话切换、侧边栏刷新和窄窗口布局。
- 专家与子 agent 支持采样参数的保存、继承和单独覆盖；改进模型请求、提示缓存与图片上下文估算。
- 优化桌面宠物的轮廓命中、缩放把手和贴边移动，Clippy、Rover 与鲸鱼娘切换时保留贴边状态。
- 补齐 macOS 操控的键盘焦点指针反馈和点击视觉反馈，扩展独立悬浮窗验证；优化运行数据命名迁移及旧目录兼容。

升级后请完整重启 ACECode。默认专家管理 Skill 会在下次启动时按新 seed 版本同步，保留用户修改的内容。Agent Browser 集成于 Desktop，无需独立浏览器宿主或扩展。
