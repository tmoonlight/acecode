# 好好工作事务所

等距像素风 AI 办公室 demo。参考用户提供的办公室画面，全部使用 Canvas 代码绘制；团队与任务为本地模拟，没有真实模型请求。

## 打开

双击本目录的 **index.html**，使用 Chrome 或 Edge 打开即可。不需要安装依赖、启动服务器或联网。请保留同目录的 CSS 和四个 JS 文件。

默认自动演示一个进行中的项目。开启系统“减少动态效果”时默认暂停，可手动点击“继续”。

## 可以体验什么

- 6 位伙伴分别负责规划、开发、设计、研究、审查和测试。
- 点击小人或右侧成员按钮查看当前任务；成员按钮支持键盘操作。
- 小人打字、眨眼，空闲时沿过道走去咖啡角，再回到工位。
- 按依赖交接任务；整个项目完成后，“派发新任务”会启用。
- 暂停/继续、1×/2×/4×、80%–140% 缩放、适应窗口。页面背景获得焦点时，空格也可暂停。
- “素材图鉴”展示共享家具与人物；Escape 关闭图鉴。

## 资源复用

| 文件 | 唯一职责 |
| --- | --- |
| assets.js | 整数像素光栅、等距几何、家具工厂、人物模板、Atlas 缓存 |
| simulation.js | 角色数据、通道移动、咖啡角占用、显式时间驱动的任务依赖 |
| renderer.js | 缓存房间、家具实例布局、深度排序、人物与气泡合成、坐标命中 |
| app.js | DOM 交互、动画调度、名册、详情与素材图鉴 |
| office.css | 独立原型的响应式视觉系统 |

- 地面重复使用 4 个配色图块；重复工位、椅子、隔板、绿植引用同一个缓存对象。
- 人物共享同一套轮廓，通过发型、衣服、肤色和有限动作帧换色组合；头像与图鉴也取自同一 Atlas。
- 墙壁、窗户、地板与光照只绘制一次到离屏 Canvas。家具实例只存位置与资源引用。
- 最多 30 FPS 渲染，DOM 状态约每 220ms 更新一次；暂停、页面隐藏或打开图鉴时取消连续动画调度。
- 缓存按资源类型、配色、动作和有限帧编号索引，不随运行时间无限增长。图鉴提供当前图块数和像素缓冲区估算，不包含浏览器自身开销。
- **外部图片、字体、运行时依赖均为 0。** 源图不会作为背景贴图或资产被加载。

新增一种家具：在 assets.js 的家具工厂中定义它，再向 renderer.js 的 furniture 数组添加实例。重复实例不需要重新绘制素材。修改角色外观只需修改 profiles 的配色与样式字段。

将来接入真实 Agent Team 时，可保留 Atlas 和 Renderer，用真实事件驱动的状态适配器替换 Simulation；维持 actor 位置、action、任务进度和 status 的数据接口即可。本 demo 尚未接入 ACECode 正式界面。

## 验证

状态机使用 Node 内置测试，无额外测试依赖：

~~~powershell
node --test design-prototypes/agent-office/simulation.test.cjs
~~~

已验证：

- 7 项状态机测试：暂停、倍速、无效时间、任务依赖、工位约束、咖啡往返、重复派发与完整完成。
- Chromium 的 file 页面和本地 HTTP 页面；没有外部网络请求和页面脚本错误。
- 鼠标/键盘成员选择、场景命中、缩放、图鉴及完成后的任务派发。
- 暂停时模拟时间不变且没有连续绘制；隐藏页面和图鉴打开时不推进。
- 320 / 390 / 768 / 1024 / 1440px 布局无横向溢出；桌面、手机和 150% DPI 截图检查。
- 仓库 web 的 pnpm test、pnpm build，以及本次 OpenSpec 严格校验通过。
